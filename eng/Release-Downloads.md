## Choose a download

- **`KOTU-win-Setup.exe`** — Install KOTU with Start menu registration and automatic updates.
- **`KOTU-win-Portable.zip`** — Extract to a folder and run `KOTU.exe`. Includes automatic updates and saved settings.
- **`KOTU-win-Standalone.exe`** — Run one file directly. Updates and Explorer registration are disabled; settings and playback history last only for the session. Files are extracted to a private temporary folder and removed on normal exit. The launcher uses the Windows .NET Framework runtime; the application includes .NET 8.

The required archive, image, and media engines are included. See `THIRD-PARTY-NOTICES.md` for their licenses.

The remaining assets (`*.nupkg`, including delta packages, `*.json`, and `RELEASES`) support automatic updates. Choose one of the three downloads above to run KOTU.
