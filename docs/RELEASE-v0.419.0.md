# v0.419.0 — 미리보기·목록 바로 전환

탐색기의 기존 View 드롭다운을 미리보기 격자와 목록을 나타내는 두 아이콘 버튼으로 바꿨다. 두 버튼이 항상 표시되어 메뉴를 열지 않고 한 번의 클릭으로 보기를 전환할 수 있다. 현재 보기는 선택된 버튼으로 표시하며, 같은 버튼을 다시 눌러도 선택이 해제되지 않는다.

버튼에 Preview와 List 설명 및 접근성 이름을 제공한다. Tab으로 이동하고 Space나 Enter로 전환할 수 있으며, 기존 테마의 버튼·선택 표시를 사용한다. 창 폭이 좁으면 보기 전환 버튼 묶음이 함께 다음 줄로 이동한다.

보기 전환 시 기존 선택·체크와 위치 복원 동작을 유지한다. v0.418.0에 반영한 첫 행 상위 이동과 열 제목 정렬도 유지한다. 이번 변경은 앞서 선택한 시안에서 누락됐던 보기 선택 UI를 보완한다.
