# A86 키 동작 표 — 확정본 (2026-08-13 사용자 합의 완료)

> **v0.121.0 구현 완료** — S4 행은 **A90(v0.122.0)이 구현 완료**('오픈 파일' 버튼·S4 진입/복귀 포함),

> + A90(Esc·오픈 파일) + A98(휠 — v0.123.0 반영 완료) + A34 키 맵 + A84(Shift+N·Ctrl+S).
> **전 쟁점(Q1~Q10) 사용자 확정 완료** — 이 파일이 A86의 구현 사양이자 **A87 단축키 장의 원본**이다.

## 상태 정의 (v2 — 사용자 지적으로 좌만/우만 분리)

| 상태 | 설명 |
| --- | --- |
| S1 | 탐색기 상태 — 콘텐츠 없음, 3구획(A93) 도크 표시 |
| S2 | 콘텐츠 열림 + 좌/우 전부 닫힘 |
| S3L | 콘텐츠 열림 + **좌측만** 열림 |
| S3R | 콘텐츠 열림 + **우측만** 열림 |
| S3B | 콘텐츠 열림 + 좌·우 모두 열림 |
| S4 | **'오픈 파일' 탐색 모드** — 아래 단일 규칙으로 구성 |

**S4 구성 규칙 (Q10 확정 + 사용자 정련)**: '오픈 파일' 진입 시 **이미 떠 있는 구획은 그대로 두고
(그 위에 다시 얹지 않는다), 없는 구획만 반투명으로 추가하며, 가운데 콘텐츠 영역은 반투명 썸네일
탐색기로 덮는다.**
- S2에서 진입 → 4구획(좌상 트리/좌하 리스트/중앙 썸네일/우 인포) 전부 반투명 (A90-a 원안).
- S3B에서 진입 → 좌/우는 기존 그대로, **중앙만 반투명 썸네일** (사용자 지시 그대로).
- S3L/S3R에서 진입 → 있는 쪽 유지, **없는 쪽 반투명 추가 + 중앙 반투명 썸네일** (위 규칙의 일반화 —
  사용자가 명시한 건 S3B 사례이므로, 다르게 원하면 정정받을 것).
- Esc/'오픈 파일' 재누름 = **진입 전 상태로 복귀** — 이번에 추가된 것만 내려가고, 원래 있던 구획은
  원래 모습(불투명이면 불투명) 그대로 남는다.
- S1에서 '오픈 파일' = 새로 띄울 것 없음 → "이미 열려 있음" 강조만 (A90-b, 복귀 개념 없음).

## 포커스 예외 (확정)

- **텍스트 입력 포커스**: Z·X·Enter·문자 핫키 전부 입력 우선(A32·A34 통과 규칙 재사용). Esc만 통과.
- **리스트/트리/썸네일 포커스**: **Z/X는 타이핑 탐색(첫 글자 점프) 우선** (Q4 확정) — 오버레이 여닫기는
  Enter·경계 버튼·마우스로.

## 안전장치 (확정)

- Alt의 OS 메뉴 회피 로직 **제거**, 홀드 취소 트리거(다른 키·클릭·휠 개입)는 **유지** — Ctrl+휠 줌 개입도
  취소로 취급 (Q6 확정).

## Enter "다시 살리기"의 복원 대상 (Q3 확정 = 안 ①)

**직전 구성 복원** — 예: 좌측만 열어 두고 Enter로 전부 닫았다면, 다시 Enter 시 **좌측만** 다시 열린다.
세션 내 기억이며, 기억이 없으면 A81 기본 세트(좌+우 도크)로 연다. 저장하지 않는다(세션 한정).

## 트레이 3자 표기 (Q9 확정 — A54로 이관, v0.118.0 구현 완료)

IMG / VID / AUD / DOC / **ARC** / ALL. 유휴 = 1줄 중앙·저채도, 열림 = 2줄(상단 확장자·하단 값)·모듈 색.
정보(하드웨어) 모듈은 **INF**(A54 구현 시 결정 — 표시 값이 상수라 셸의 모듈 ID 표가 담당).
