# A86 키 동작 표 — 확정본 (2026-08-13 사용자 합의 완료)

> **v0.121.0 구현 완료** — S4 행은 **A90(v0.122.0)이 구현 완료**('오픈 파일' 버튼·S4 진입/복귀 포함),
> 휠 행은 **A98(v0.123.0)이 구현 완료**.
> **개정: A107(v0.134.0)** — 전역 키 Alt 조합 전환: 단독 \`·숫자·Z/X 폐지 → **Alt+\`/Alt+숫자/Alt+Z·X**,
> **Alt+Z+X 동시 호출 행 신설**, Alt 단독 OS 메뉴 모드 회피 재도입(조건 소비). 전이 체계는 무변경.
> **개정: A118(v0.144.0)** — 좌/우 패널 키 = **F1(좌)/F2(우) 단독 키**(Alt+Z/X 폐지 — 병행 없음).
> 전이·상태 체계 무변경, F1+F2 동시 = 구 Alt+Z+X 규칙 승계, 텍스트 입력 중에도 동작(문자 비생성).
> 탐색기 표면의 F2 = 이름변경(A94)이 원 기능 우선 — 선택 항목을 소비하면 패널이 양보한다.
> Alt+\`·Alt+숫자·Alt+0은 무변경.
> **개정: A147(v0.163.0)** — **Alt+숫자(모듈 전환)·Alt+0(Settings) 폐지**. 셸에 남는 Alt 조합은
> **Alt+\`(시작 메뉴) 하나뿐**이다 — 모듈 전환·설정 진입은 시작 메뉴로만 하고 메뉴 항목의 키 툴팁도
> 사라졌다. 전이·상태 체계·F1/F2·Shift+N·Ctrl+S·A34 문자 핫키는 무변경.
> **보강: A94 6차(v0.153.0)** — Enter "선택 열기"에 **다중 선택 일괄 열기**(상한 10) 명기(A132에서
> 누락 정리). 전이·상태 체계는 무변경이고 Enter 행과 아래 주만 보강했다.
> **개정: A151(v0.175.0) — 전체화면 3단 체계**: **A86의 "Enter = 좌/우 일괄 토글"은 폐지**됐다.
> Enter는 이제 **셸 표시 모드 순환**(모드1 창+하단 바 → 모드2 Full window → 모드3 Full screen → 모드1,
> 한 방향)이고, **Alt+Enter = 어느 상황에서든 모드3 직행 + 복귀 지점 기억**(모드3에서 다시 누르면 복귀),
> **Esc = 한 단계 되돌리기**(모드3 → 복귀 스냅샷 / 모드2 → 모드1 / 그다음이 S4 복귀)다. 하단 바 우측에
> **모드 버튼 2개**(Full window / Full screen)가 생겼고, **모듈별 F11·Esc 전체화면 액셀러레이터 8벌은
> 전부 제거**됐다 — 전체화면 진입·해제는 셸 한 곳이다. 좌/우 패널 전이 체계 자체는 무변경.
> **개정: A158 — 좌/우 패널 키 = F11(좌)/F12(우)**(구 A118 F1/F2). A151이 F11을 전체화면 매핑에서
> 뺀 뒤라야 성립하는 순서 의존이었다. 전이·상태 체계 무변경, F11+F12 동시 = 구 규칙 승계, 텍스트
> 입력 중에도 동작(문자 비생성). **탐색기 표면의 F2 = 이름변경은 F2 그대로 유지** — 패널 키가 F12로
> 옮겨가 **양보(원 기능 우선) 상황 자체가 소멸**했다(표면 코드·소비 규칙은 무변경).
> **개정: A176(부록 B 72) — 반투명 오버레이 축 전면 폐지.** 패널 상태 = **닫힘/사이드바(불투명)
> 2상태**뿐이고, **F11/F12 단타 = 그 쪽 토글**이 전부다 — A58 계보의 홀드(반투명 덮기)/2초
> 홀드(반투명 피닝)/2연타(불투명) 전이 체계와 그 안전장치(다른 키·포인터 개입 = 홀드 취소)는
> 통째로 폐지됐다. **경계 버튼은 핀(사이드바 토글) 1개** — A154의 위 버튼(순간 표시 peek)과
> peek 기능 자체가 삭제됐다(대체 없음). A108의 "오버레이(반투명)" 용어는 은퇴했다 — 남은 것은
> 사이드바뿐이다. S4가 추가하는 구획도 사이드바다(구 "반투명 추가" 소멸).
> **개정: A186 — 모드2(Full window) 폐지 + Enter = Alt+Enter + 영상 하단 바 자동 숨김.**
> 표시 모드 = **창/전체화면 2단**. **Enter와 Alt+Enter는 같은 전체화면 토글**(진입 시 패널 구성
> 스냅샷, 복귀 시 되살림)이고 원 기능 우선(문서 편집 = 줄바꿈 / 탐색기 표면 = 선택 열기)은
> Enter 쪽에만 그대로다. Esc의 모드2 분기·하단 바 Full window 버튼은 모드2와 함께 삭제(버튼은
> Full screen 1개). **영상 재생 중 무입력 3초면 하단 바가 자동 숨김**되고 포인터 이동·터치·
> 하단 근접·일시정지·정지로 돌아온다 — 전체화면에서도 동일(= 영상에서는 전체화면 중에도
> 입력이 오면 바가 나타난다).

> A86 착수의 선행 조건(부록 B 36·48·49). 재료: A58 동작 체계 + A86(Z/X·Enter 일괄 토글·경계 버튼)

> 뒤 사이드바 기본이 얹힌다. 같은 모듈 재선택(`OpenModuleById` no-op)은 화면을 건드리지 않는다.
> 파일 인자로 직접 연 창(S2)의 무사이드바 기본은 그대로다(A81).

## 포커스 예외 (확정 — A107 개정 → A118 개정 → A151·A158 개정 → A176·A186 개정)

- **텍스트 입력 포커스**: Enter·문자 핫키는 입력 우선(A32·A34 통과 규칙 재사용). Esc만 통과.
  **Alt+Enter도 통과**(A151 — 직행 단축키라 텍스트 입력 판정보다 앞에서 받는다).
  **Alt+\`(A147 뒤 유일한 Alt 조합)와 F11/F12(A158)는 텍스트 입력 중에도 동작** — 문자를 만들지 않아 뺏을 입력이
  없다(구 Z·X 입력 우선 예외는 단독 문자 키 폐지로 소멸 — "외부 탐색기에서 연 직후 무반응" 해소의 본체).
  Enter의 통과·소비 규칙은 A186 뒤에도 그대로다(동작만 순환 → 전체화면 토글).
- **리스트/트리/썸네일 포커스**: 구 Q4 예외("Z/X는 타이핑 탐색 우선")는 **소멸** —
  첫 글자 점프는 단독 문자 키만 쓰므로 F11/F12와 충돌하지 않는다(리스트 포커스에서도 패널 토글 동작).
  Enter는 종전대로 선택 항목 열기 우선(선택이 없으면 표면 양보로 전체화면 토글도 일어나지 않는다).
  **탐색기 표면의 F2 = 이름변경(A94)과의 충돌은 A158에서 소멸**했다 — 패널 키가 F12로 옮겨가 두 키가
  겹치지 않는다(표면의 "선택이 있을 때만 소비" 규칙은 무변경).
  이름변경 편집 상자 활성 중의 F11/F12는 문자를 안 만들어 편집을 방해하지 않는다(패널 키로 동작).
- **PDF 스크롤 키(A121, v0.146.0)**: ↑↓·PgUp/PgDn·Home/End는 **문서 모듈이 PDF를 표시 중일 때만**
  뷰어 스크롤로 소비한다(수신 = DocumentView의 터널링 PreviewKeyDown). 텍스트 에디터·잘림 뷰·빈
  화면은 즉시 통과이고(캐럿 이동이 원 기능), PDF 중에도 ① 텍스트 입력 포커스 ② 탐색기 표면
  (PassThroughTag) 포커스 ③ 수정키 조합(Ctrl+Home 등)은 통과한다 — 판정은 A34 공용
  `HotkeySupport.ShouldPassThrough` 재사용. **오토리피트는 걸러내지 않는다**(꾹 누르면 연속 스크롤이
  사양 — 토글·전이 키인 F11/F12·문자 핫키가 오토리피트를 버리는 것과 반대). 셸 전역 키에는 이 여섯
  키가 없어 충돌 없음(A34 문자 핫키·A158 F11/F12·Alt 조합 전수 확인).

## 안전장치 (확정 — A107 개정, A176 뒤 잔존 = Alt 회피 하나)

- Alt의 OS 메뉴 회피: A86이 제거했던 것을 **A107이 재도입** — **우리 조합에 쓰인 Alt의 단독 up만 소비**
  (깨끗한 Alt 단독 탭·Alt+Tab·Alt+F4·Alt+Space는 OS 기본 동작 그대로).
  A118·A147 뒤에도 **Alt+\` 액셀러레이터 하나**가 쓰므로 존치 — 지우면 Alt를 눌렀다 뗄 때마다 창 메뉴 모드로 빠진다.
- ~~홀드 취소 트리거(다른 키·클릭·휠 개입)~~ — **A176에서 홀드 판정 기계와 함께 폐지**(Q6의
  취소 규칙·Alt/F11↔F12 예외 2종 포함). 단타 토글에는 취소할 진행 상태가 없다.

## Enter "다시 살리기"의 복원 대상 (Q3 확정 = 안 ① — A151에서 폐지, A186에서 재단순화)

**A151(v0.175.0)이 "Enter = 좌/우 일괄 토글"을 폐지**했고, **A186이 그 3단 순환마저 전체화면
토글로 단순화**했다 — Enter가 패널을 여닫는 경로는 없다. 유일한 "구성 기억"은 **전체화면 복귀
스냅샷**뿐이다: Enter·Alt+Enter·Full screen 버튼으로 전체화면에 들어갈 때 그 직전의 좌/우 패널
구성(닫힘/사이드바 — A176 2상태)을 기억했다가 Enter·Esc·Alt+Enter로 나올 때 되돌린다
(세션 내·창별, 저장 없음).
기록 보존용 구 규칙: 직전 구성 복원 — 좌측만 열어 두고 Enter로 전부 닫았으면 다시 Enter 시 좌측만.
