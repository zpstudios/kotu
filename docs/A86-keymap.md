> 입력이 오면 바가 나타난다).
> **개정: A196+A201+A202(v0.204.0) — 패널 게이트 완화 + Esc 콘텐츠 닫기 층.** ① **F11/F12·경계
> 버튼이 무제 문서(A189)·설정 화면·미지원 파일 안내에서도 동작**한다(패널 컨텍스트 편입 —
> 좌 리스트 = 전역 마지막 폴더(A174, 무제 = 문서 모듈 필터 / 설정·미지원 = **전체 파일 필터**),
> 우 정보 = "No file open" 플레이스홀더). 컨텍스트 예외로 남는 것은 빈 셸뿐이고 **S4 중 무동작은
> 사양 그대로 존치**. ② **Esc 체인 말단에 "콘텐츠 닫기" 층 신설**: 전체화면 복귀 → S4 복귀 →
> **콘텐츠(무제 포함) 닫기 — 닫은 뒤 기본 사이드바(A109) 적용**(파일 인자 실행(A81 무사이드바)
> 에서 Esc 하나로 아이콘 실행 기본 화면과 동일해진다 — 사용자 문면). '뒤로'(A112)의 콘텐츠 닫기
> 층은 종전대로 패널 상태 보존(defaultSidebars=false) — 두 입력의 의도된 차이다. 문서 더티면
> 닫기 가드(A37) 경유. ③ **탐색기 표면의 Esc = 잘라내기 표시 해제(A94 4차)는 "지운 표시가 있을
> 때만 소비"로 개정** — 한 Esc가 두 층(표시 해제 + 닫기/S4 복귀)을 움직이지 않게 한 층씩 규칙에
> 정렬했다. 전수 매트릭스·수리 근거 = docs/A196-key-audit.md.
> **개정: A203(v0.205.0) — 전체화면 진입 시 좌/우 사이드바 자동 닫힘.** 진입 스냅샷(직전 구성
> 기억)은 그대로 두되, 스냅샷을 기록한 **뒤** 양쪽 패널을 닫는다(콘텐츠 전용 화면 — 구 "패널은
> 건드리지 않는다" 폐지). 전체화면 중 F11/F12는 종전대로 동작하고(A153/A196 불변), 복귀는 스냅샷
> 우선 — 전체화면에서 연 패널도 복귀 시 진입 전 구성으로 덮인다.
> **개정: A205(v0.208.0) — 설정 화면은 좌/우 사이드바 전면 배제(위 A196 ①의 부분 반전).**
> 사용자 확정("설정 모듈은 좌우 사이드바 안 떠야 해"): 설정 화면에서 **F11/F12·경계 버튼은 전부
> 무동작**이고 어떤 경로로도 사이드바가 뜨지 않는다 — 패널이 열린 채 설정에 들어가면 함께
> 내려간다(좌/우 상태는 보존해 설정을 나가면 직전 구성으로 복원). **미지원 파일 안내·무제
> 문서의 A196 편입분은 그대로 유지**된다. 컨텍스트 예외 = 빈 셸 **+ 설정 화면**.
> **신설: A211 배치 1(v0.220.0) — Ctrl+P = 인쇄(OS 표준 인쇄 대화상자, 부록 B 78 확정).**
> 인쇄 계약(IPrintPageProvider)을 구현한 모듈 뷰에서 인쇄할 콘텐츠가 있을 때만 동작 —
> 대상은 **3모듈 한정**(이미지·PDF·텍스트/마크다운 문서, 계약 구현은 배치 2~5)이고 미구현
> 뷰·빈 셸·설정·S4에서는 무동작이다. 텍스트 입력 중에도 동작(문자 비생성 — Alt+`와 같은
> 규칙, 문서 편집 중 인쇄가 주 사용처). 구형 Win10(KB5023773 미적용)은 영어 안내 다이얼로그로
> 닫힌다. 모듈 하단 바 인쇄 버튼이 배치 2~5에서 병행 추가된다. 전이·상태 체계는 무변경.
> **개정: A305 배치 1 — 모드 2 부활(3단 계단) + F11/F12 사이드바 오버라이드(A186 반전).**
> ① 표시 모드 = **모드1(창 + 하단 바 + 사이드바) / 모드2(사이드바만 사라짐 — 제목표시줄·하단 바·
> 창 크기 그대로) / 모드3(전체화면)**. **콘텐츠가 열려 있을 때 Enter·Alt+Enter = 1 → 2 → 3 → 1
> 계단**(모드3 다음이 모드1 — 토글 아님). 콘텐츠가 없는 화면(S1 썸네일·설정·정보 모듈·미지원
> 안내)에서는 **A186의 전체화면 토글 그대로**다. ② **Esc·'뒤로' = 모드2·모드3 어디서든 한 번에
> 모드1**, 그다음 층은 종전대로 S4 복귀 → 콘텐츠 닫기다. ③ **하단 바 전체화면 버튼 = 일반 → 전체
> 단방향**(A186의 토글 폐지 — 전체화면에서는 버튼이 비활성). ④ **F11/F12(또는 같은 전이인 경계 핀
> 버튼)를 한 번이라도 쓰면 사이드바 오버라이드가 확정**되어 창이 닫힐 때까지 유지된다(취소 불가):
> 그 뒤로는 **모드1/2 구분이 사라지고 커스텀 일반 ↔ 커스텀 전체화면 2단**만 남으며(Enter 양방향),
> **전체화면에서도 사이드바가 사용자 구성 그대로** 남는다. 오버라이드 확정 시점에 화면에 보이던
> 구성이 요청 상태로 승계되므로 억제 중(모드2·모드3)에 누른 첫 F11/F12는 항상 "그 사이드바 열기"가
> 된다. ⑤ A203(전체화면 진입 시 자동 닫힘)·A274(복귀 스냅샷)는 **폐지가 아니라 계산으로 대체**됐다 —
> 실효 사이드바 = f(요청 상태, 모드, 오버라이드) 한 함수가 같은 왕복을 만든다(스냅샷 필드 소멸).
> 좌/우 패널 전이 체계·S4 규칙·경계 버튼 규칙 자체는 무변경. ※ 하단 바 버튼 2종(1→2 · 2→3) 신설은
> **배치 2** 몫이다 — 배치 1은 기존 버튼 1개를 2→3에 연결만 했다.

## 용어 (A108, v0.135.0 확정 → **A176 개정: 오버레이 축 은퇴**)

- **사이드바** = 불투명 패널 — 메인 영역을 줄이며 옆에 선다(구 "불투명 도크/밀어내기". F11/F12
  단타·경계 핀 버튼·A81 기본 세트가 만드는 유일한 열림 상태. 폭은 전 상태 공통 25% — A116).
- ~~**오버레이** = 반투명 패널~~ — **A176에서 폐지**(홀드·2초 홀드 고정과 함께 반투명 표시 축

**S4 구성 규칙 (Q10 확정 + 사용자 정련 — A176 개정)**: '오픈 파일' 진입 시 **이미 떠 있는 구획은
그대로 두고(그 위에 다시 얹지 않는다), 없는 구획만 사이드바로 추가하며, 가운데 콘텐츠 영역은
썸네일 탐색기로 덮는다**(구 "반투명 추가·반투명 썸네일"은 A176 반투명 축 폐지로 전부 불투명).
- S2에서 진입 → 좌/우 사이드바 추가 + 중앙 썸네일.
- S3B에서 진입 → 좌/우는 기존 그대로, **중앙만 썸네일** (사용자 지시 그대로).
- S3L/S3R에서 진입 → 있는 쪽 유지, **없는 쪽 사이드바 추가 + 중앙 썸네일**.

- **그래프 크기 키·휠(A237, v0.252.0)**: 정보(H/W) 모듈이 같은 키 집합(Ctrl+±·Ctrl+넘패드 '*')을

## Enter "다시 살리기"의 복원 대상 (Q3 확정 = 안 ① — A151에서 폐지, A186에서 재단순화)

**A151(v0.175.0)이 "Enter = 좌/우 일괄 토글"을 폐지**했고, **A186이 그 3단 순환마저 전체화면
토글로 단순화**했다 — Enter가 패널을 여닫는 경로는 없다. 유일한 "구성 기억"은 **전체화면 복귀
스냅샷**뿐이다: Enter·Alt+Enter·Full screen 버튼으로 전체화면에 들어갈 때 그 직전의 좌/우 패널
구성(닫힘/사이드바 — A176 2상태)을 기억했다가(A203: 기억한 직후 양쪽 패널은 자동으로 닫힌다 —
콘텐츠 전용 화면) Enter·Esc·Alt+Enter로 나올 때 되돌린다(세션 내·창별, 저장 없음).
기록 보존용 구 규칙: 직전 구성 복원 — 좌측만 열어 두고 Enter로 전부 닫았으면 다시 Enter 시 좌측만.
