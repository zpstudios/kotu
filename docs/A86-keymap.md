# A86 키 동작 표 — 확정본 (2026-08-13 사용자 합의 완료)

> **v0.121.0 구현 완료** — S4 행은 **A90(v0.122.0)이 구현 완료**('오픈 파일' 버튼·S4 진입/복귀 포함),
> 휠 행은 **A98(v0.123.0)이 구현 완료**.
> **개정: A107(v0.134.0)** — 전역 키 Alt 조합 전환: 단독 \`·숫자·Z/X 폐지 → **Alt+\`/Alt+숫자/Alt+Z·X**,
> **Alt+Z+X 동시 호출 행 신설**, Alt 단독 OS 메뉴 모드 회피 재도입(조건 소비). 전이 체계는 무변경.
> **개정: A118(v0.144.0)** — 좌/우 패널 키 = **F1(좌)/F2(우) 단독 키**(Alt+Z/X 폐지 — 병행 없음).
> 전이·상태 체계 무변경, F1+F2 동시 = 구 Alt+Z+X 규칙 승계, 텍스트 입력 중에도 동작(문자 비생성).
> 탐색기 표면의 F2 = 이름변경(A94)이 원 기능 우선 — 선택 항목을 소비하면 패널이 양보한다.
> Alt+\`·Alt+숫자·Alt+0은 무변경.

> A86 착수의 선행 조건(부록 B 36·48·49). 재료: A58 동작 체계 + A86(Z/X·Enter 일괄 토글·경계 버튼)
> + A90(Esc·오픈 파일) + A98(휠 — v0.123.0 반영 완료) + A34 키 맵 + A84(Shift+N·Ctrl+S).
> **전 쟁점(Q1~Q10) 사용자 확정 완료** — 이 파일이 A86의 구현 사양이자 **A87 단축키 장의 원본**이다.
> (경위: v1 초안 → 사용자 1차 검토로 Q1·Q2·Q4~Q10 확정·상태 좌만/우만 분리·Q10 정련 → Q3 = 안 ① 확정.)

## 용어 (A108, v0.135.0 확정)

- **사이드바** = 불투명 패널 — 메인 영역을 줄이며 옆에 선다(구 "불투명 도크/밀어내기". 2연타·경계 버튼·A81 기본 세트가 만드는 상태. 폭은 전 상태 공통 25% — A116).
- **오버레이** = 반투명 패널 — 메인 위에 덮이며 공간을 차지하지 않는다(키 홀드 / 2초 홀드 고정 = 구 "반투명 덮기/고정").

(그 위에 다시 얹지 않는다), 없는 구획만 오버레이(반투명)로 추가하며, 가운데 콘텐츠 영역은 반투명
썸네일 탐색기로 덮는다.**
- S2에서 진입 → 4구획(좌상 트리/좌하 리스트/중앙 썸네일/우 인포) 전부 오버레이(반투명) (A90-a 원안).
- S3B에서 진입 → 좌/우는 기존 그대로, **중앙만 반투명 썸네일** (사용자 지시 그대로).
- S3L/S3R에서 진입 → 있는 쪽 유지, **없는 쪽 오버레이 추가 + 중앙 반투명 썸네일** (위 규칙의 일반화 —
  사용자가 명시한 건 S3B 사례이므로, 다르게 원하면 정정받을 것).
- Esc/'오픈 파일' 재누름 = **진입 전 상태로 복귀** — 이번에 추가된 것만 내려가고, 원래 있던 구획은
  원래 모습(사이드바면 사이드바) 그대로 남는다.
- S1에서 '오픈 파일' = 새로 띄울 것 없음 → "이미 열려 있음" 강조만 (A90-b, 복귀 개념 없음).

## 포커스 예외 (확정 — A107 개정 → A118 개정)

- **텍스트 입력 포커스**: Enter·문자 핫키는 입력 우선(A32·A34 통과 규칙 재사용). Esc만 통과.
  **Alt 조합(Alt+\`/숫자)과 F1/F2(A118)는 텍스트 입력 중에도 동작** — 문자를 만들지 않아 뺏을 입력이
  없다(구 Z·X 입력 우선 예외는 단독 문자 키 폐지로 소멸 — "외부 탐색기에서 연 직후 무반응" 해소의 본체).
- **리스트/트리/썸네일 포커스**: 구 Q4 예외("Z/X는 타이핑 탐색 우선")는 **소멸** —
  첫 글자 점프는 단독 문자 키만 쓰므로 F1/F2와 충돌하지 않는다(리스트 포커스에서도 오버레이 동작).
  Enter는 종전대로 선택 항목 열기 우선. **탐색기 표면의 F2 = 이름변경(A94)이 원 기능 우선**(A118) —
  표면이 선택 항목으로 F2를 소비(Handled)하면 우 패널이 양보하고, 선택이 없으면 패널 키로 동작한다.
  이름변경 편집 상자 활성 중의 F1/F2는 문자를 안 만들어 편집을 방해하지 않는다(패널 키로 동작).

## 안전장치 (확정 — A107 개정, A118 뒤에도 유지)

- Alt의 OS 메뉴 회피: A86이 제거했던 것을 **A107이 재도입** — **우리 조합에 쓰인 Alt의 단독 up만 소비**
  (깨끗한 Alt 단독 탭·Alt+Tab·Alt+F4·Alt+Space는 OS 기본 동작 그대로).
  A118 뒤에도 Alt+\`·Alt+숫자 액셀러레이터가 쓰므로 존치.
- 홀드 취소 트리거(다른 키·클릭·휠 개입)는 **유지** — Ctrl+휠 줌 개입도 취소로 취급 (Q6 확정).
  **예외 2종(A107 — A118 승계)**: Alt 자체(수식키 — 취소 트리거 아님)와 F1↔F2 상호(동시 호출 성립,
  구 Z↔X 규칙).

## Enter "다시 살리기"의 복원 대상 (Q3 확정 = 안 ①)

**직전 구성 복원** — 예: 좌측만 열어 두고 Enter로 전부 닫았다면, 다시 Enter 시 **좌측만** 다시 열린다.
세션 내 기억이며, 기억이 없으면 A81 기본 세트(좌+우 사이드바)로 연다. 저장하지 않는다(세션 한정).
