# A362 사용자 인터페이스 정합성 개선 — v0.359.0

2026-09-08 · 사용자 지시에 따라 master에서 직접 작업한다. 하나의 승인된 묶음이다.
A363 광고 서버·분석은 별도 백로그이며 이번 구현이나 데이터 수집에 포함하지 않는다.

## 범위와 진행

- 셸은 창의 전체 화면 여부와 패널 구성을 독립 상태로 관리한다. 빈 모듈은 양쪽 패널 표시,
  새 파일·무제 문서 열기는 패널 없는 일반 창으로 초기화한다. 기본 전체 화면은 패널을 숨기고,
  F11/F12로 직접 선택한 패널 구성은 전체 화면 왕복에도 유지한다. 전체 화면 첫 패널 전환은
  실제 보이는 상태에서 시작한다. 같은 파일의 중복 완료와 저장 경로 변경은 구성을 초기화하지 않는다.
  S4 임시 탐색 화면을 나가면 콘텐츠 구성을 복원한다. 모드 해석은 구현 가정이며,
  오케스트레이터의 확인 질문에 답변이 없어 확정된 사용자 사양으로 기록하지 않는다.
- Image/Document/All Readable의 공통 Print·Zoom·Fit 위치, Audio/Video의 공통 재생 조작 위치,
  Fit 화살표 스타일과 바 수직 여백을 맞춘다. 존재하지 않는 Archive 기능을 되살리지 않는다.
- All Readable 빈 화면에는 사용할 수 없음을 명확히 표시한 공통 조작을 제공한다. 파일을 열면
  실제 자식 바를 그대로 전달하며 하나의 UI 요소를 두 부모에 붙이지 않는다.
- 썸네일에는 별도의 부모 폴더 버튼을 둔다. 기존 FolderActivated 경로를 재사용하며
  가짜 파일 항목을 목록에 넣지 않는다. 루트에서는 버튼을 비활성화한다.
- 해당 창의 압축 작업이 실행·암호 대기·취소 중이면 모듈/설정/다른 파일 요청을 같은 프로세스의
  새 창에 전달하고 현재 압축 창을 유지한다. 다른 창의 작업으로 전환을 제한하지 않는다.
  제목에는 해당 작업만 10칸 진행 표시와 백분율·대기 상태로 나타내고 완료 시 제거한다.
- 문서는 편집기와 장식이 TextLineIndex를 공유하고, 한 장식 렌더 작업 안에서 문자 사각형을
  재사용한다. 모든 장식이 꺼지면 좌표 조회를 건너뛴다. 가이드 버튼은 줄 가이드와 줄 번호를
  함께 켜고 끈다. 텍스트는 선택 시작점의 현재 논리 줄 / 전체 논리 줄, PDF는 현재p / 전체p를
  표시한다. 예시는 `3 / 20`, `3p / 20p`다. 줄바꿈 기준 논리 줄 해석과 이 표기 형식은 구현
  가정이며 사용자 확정 답변은 아니다. 숨은 편집기의 선택 통지가 PDF 페이지 표시를 덮지 않게 한다.
  저장 후 경로 통지는 같은 콘텐츠의 메타데이터 변경으로 처리한다. 최적화 효과는 실제 측정
  없이 수치나 체감 개선으로 단정하지 않는다.

## 하단 바 좌표 계약

같은 창 폭·UI 배율·셸 하단 바 가시성에서 비교한다. 버튼은 32×32, 일반 간격은 6,
Fit 본체와 화살표는 32+32이며 사이 간격은 0이다. 모듈 바의 오른쪽 끝을 R로 둔다.

- Image/Document/All Readable 빈 바: Zoom 84가 [R-192,R-108], Print 32가
  [R-102,R-70], Fit 64가 [R-64,R]를 사용한다. Image 회전은 왼쪽 고유 기능군이다.
- Video Fit도 [R-64,R]이다. Audio 고유 버튼 3개와 Video 자막+Fit의 전체 폭·간격을
  같게 유지해 Mute·Volume·Speed 위치도 맞춘다. 빈 정렬 간격은 Fit 뒤가 아니라 앞에 둔다.
- Audio/Archive에 없는 Print·Zoom·Fit 192px를 강제로 예약하지 않는다. 기존 좁은 창의
  가변 미디어 탐색 영역을 보존하기 위한 제한이며, 공통 실제 기능의 위치 정합성은 유지한다.
- 바 외곽 수직 패딩은 한 번만 적용한다. All Readable은 자식 바에 추가 패딩을 더하지 않는다.
