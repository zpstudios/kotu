# v0.435.0

- Ctrl+F now finds text in PDF and HWP documents, including HWP page and text views in Document and All Readable.
- Search results highlight the current match and support next/previous navigation with Enter, F3 and their Shift variants. Escape returns focus to the document while keeping its page view and zoom.
- PDF files without searchable text show an explicit message. Search is read-only and does not add editing or replacement to PDF or HWP files.
