# v0.433.0 — 11가지 전체 화면 디자인

Settings → Display의 **Interface design**에서 11가지 디자인을 선택할 수 있습니다. 아이콘과 글자, 체크 표시, 좌우 패널과 하단 조작부가 선택한 디자인에 맞춰 바뀝니다.

**Single view**에서는 Previous·Next로 한 디자인씩 살펴보고, **Gallery view**에서는 여러 미리보기를 나란히 비교할 수 있습니다. 미리보기를 고른 뒤 **Apply design**을 누르면 열린 파일과 편집 중인 내용, 재생·선택 상태를 유지하면서 모든 코투 창에 바로 적용됩니다. 앱을 다시 시작할 필요가 없으며 밝고 어두운 테마는 디자인 선택과 별도로 Windows 설정을 따릅니다.
