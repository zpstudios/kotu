# A413–A415 — 문서 정렬·탐색기 검색·아이콘 검수

## 2026-11-04 정식 배포 준비

사용자의 “수정을 했으면 배포해서 다운받을 수 있게 해야지!” 요청에 따라 검수 완료한 A413, A414와 승인된 A415 A안을 v0.413.0으로 커밋·푸시·정식 배포한다. 아래의 커밋·배포 없음과 배포 미승인 문구는 각 배치 당시의 이력이다. 보류 중인 A406/A407 녹화 변경은 이번 배포에서 제외하며 작업 파일은 보존한다.

배포 변경 요약과 검증 범위는 [v0.413.0 릴리스 노트](RELEASE-v0.413.0.md)를 따른다. 실제 발행과 다운로드 자산 확인은 배포 절차 완료 후 인수인계에 기록한다.

## 요청과 진행 원칙

2026-11-02 사용자 첨부 화면5개를 기준으로 한 후속 요청이다. 메인은 조율·검수·문서를 맡고 실제 구현은 GPT-6 Astra/high 한 명에게 직렬 위임한다. 한 배치 구현·검증을 마친 뒤 다음 배치로 이동한다. 보류 녹화 변경과 사용자의 현재 창·미저장 문서는 보존한다. 기존 A401 성능 개선을 되돌리거나 이전 native 편집기로 교체하지 않는다.

아이콘을 포함한 전반적인 UI 디자인 변경은 **후보 시안을 사용자에게 보여주고 검토받은 후** 실제 제품에 반영한다. 정렬 결함, 명시적으로 요청한 편집기 검정 배경, 탐색기 검색 기능은 아래 개별 구현 대상으로 분리한다. 이번 요청은 새 커밋·푸시·릴리스 승인으로 해석하지 않는다.

첨부 원본과 동일한 복사본: `artifacts/ui-followups-20261102/references/screenshot-1.png`부터 `screenshot-5.png`. 원본 경로와 SHA는 같은 루트의 `reference-manifest.json`에 보존했다.

## A413 · 문서 편집기 여백·정렬·배경

- 파란 테두리 바깥 좌측 여백이 우측보다 커 보이는 문제를 바로잡는다. 줄번호 영역과 본문 여백을 구분하며 단순히 우측에 큰 빈 공간을 추가하지 않는다.
- 본문, 줄번호, 문단 기호와 EOF의 동일 줄 세로 위치를 정렬한다. 가이드/문단 기호 켜기·끄기, 확대와 스크롤, 빈 문서/마지막 줄을 확인한다.
- Editing에서는 편집기 영역을 불투명 순수 검정 `#000000`으로 한다. Viewing의 배경과 좌우 사이드패널의 기존 배경은 유지한다. 포커스·hover 때 편집기 바탕색이 바뀌지 않아야 한다.
- 기존 연속 Enter 성능과 화면 안의 제한된 장식 계산 범위를 유지한다.
- 감사에서 파란 선은 Monaco의 포커스 outline으로 확인했다. 자세한 수정 범위와 검증 결과는 배치 보고에 기록한다.

## A414 · 탐색기 키워드 필터와 Windows식 선택 탐색

- 탐색기 모드 하단 작업표시줄의 검색 입력으로 현재 목록의 파일명을 필터링한다.
- **최종 사용자 선택**: 검색창 밖 문자 입력은 Windows식 탐색으로 한다. **목록은 유지**하고, 동일 문자만 반복하면 해당 글자로 시작하는 다음 항목을 순환 선택한다. 다른 문자를 이어 입력하면 전체 누적 문자열의 시작 일치 항목을 선택한다. `a,a,b → aab`와 시간 초과 초기화 등은 [Microsoft의 기본 ListView 설명](https://devblogs.microsoft.com/oldnewthing/20240408-00/?p=109627)을 따른다.
- 하단 검색창의 키워드 입력은 파일명 포함 일치로 목록을 좁히는 필터다. 창 밖 선택 탐색과 구분한다. 사용자의 최종 선택은 이전 ‘창 밖 입력도 접두 필터’ 지시를 대체한다.
- 연속 문자 누적/반복, 시간 초과와 폴더 이동 시 초기화, 필터 해제 동작을 명시한다. 한글 IME 조합, 이름변경/주소 등 텍스트 입력, 단축키, 문서 편집으로 문자가 새는 경우를 방지한다.
- 감사상 기존 하단 입력은 문서 본문 검색이며 빈 문서 세션에서는 비활성 안내를 표시한다. 실제 탐색기 파일명 검색과 문서 본문 검색을 모드에 맞게 연결한다.

## A415 · 아이콘과 UI 전체 감사 및 후보 시안

- 하단 작업표시줄을 중심으로 전체 모듈의 아이콘 선 굵기, 크기, 정렬, 버튼 상태, 기능 식별성을 감사한다. 다른 주요 UI의 같은 종류 불일치도 기록한다.
- Line guides and numbers의 네 칸 모양을 줄번호·줄 가이드로 알아보기 쉬운 후보로 제안한다. 문단 기호 `¶`의 식별성은 유지한다.
- 굵게 보이는 이퀄라이저를 포함해 선의 굵기를 조정한 후보를 실제 버튼 크기와 확대 비교로 제시한다.
- 스피커의 꺾인 `>>` 음파는 곡선 `))` 음파 후보를 제시한다.
- 후보는 제품 코드와 분리해 제작한다. 사용자 선택 전 제품 아이콘·일괄 UI 디자인 교체는 수행하지 않는다.
