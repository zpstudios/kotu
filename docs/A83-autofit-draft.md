# A83 Auto-fit 규칙 표 — 초안 v1 (미확정 · 사용자 보류)

> 2026-08-13 제시. 사용자 답변: "오토핏 결정하기 어려우니, 그것만 빼고 진행" — **합의 보류**.
> 다음 재론 때 이 초안에서 시작할 것. 확정 전까지 구현 금지.

## 공통 정의 (초안)

- 뷰포트 = 콘텐츠 영역(오버레이·도크 제외 실표시 영역). 창 크기·해상도·배율은 전부 뷰포트 크기에
  반영되므로 별도 해상도 조건은 두지 않는다.
- ARf = 파일 종횡비(가로/세로), ARv = 뷰포트 종횡비. 판정은 상대 비교(ARf vs ARv).
- 판정 시점 = 파일 열 때 + Auto-fit 적용 중 뷰포트 크기 변경 시(재판정 — Q5).

## 규칙 표 (초안)

| # | 조건 | 이미지 | PDF | 영상 |
|---|---|---|---|---|
| R1 | 파일이 뷰포트보다 작음(양 축 모두) | 100% | 100% | 100% |
| R2 | 큼 + 종횡비 비슷 (0.8×ARv ≤ ARf ≤ 1.25×ARv) | contain | contain | contain |
| R3 | 큼 + 세로로 긴 형태 (ARf < 0.8×ARv) | Fit width + 세로 스크롤 | Fit width + 세로 스크롤 | contain |
| R4 | 큼 + 가로로 넓은 형태 (ARf > 1.25×ARv) | Fit height + 가로 스크롤 | contain (Q3) | contain |

## 경계·연동 (초안)

- 영상은 조건 적응 제외 — 현행 A30 그대로 (Q4).
- 수동 줌 개입(Ctrl+휠 — A98 기준) 시 Auto-fit "적용 중"만 해제 — A49 규칙 유지.
- 썸네일 뷰(A93)는 줌·Fit 대상 아님(열 수 4/8 고정 — A98 확정).
- Fit width/height 수동 선택은 이 표와 무관.

## 미결 쟁점 (전부 미확정)

- Q1 판정 축 = 뷰포트 종횡비 대비 상대 비교
- Q2 문턱값 0.8 / 1.25 (상수 한 곳)
- Q3 PDF의 R4 = contain vs Fit height
- Q4 영상 제외
- Q5 뷰포트 변경 시 모드 재판정 vs 배율 추종만
- Q6 이미지 모듈 Fit UI의 A30 규격 통일 동시 진행 여부(A49 잔여)
- Q7 R1 = 업스케일 안 함
