# v0.420.0 — 보기·정렬 도구 배치와 문서 탐색 가독성 개선

탐색기의 Preview/List 보기 버튼을 상단 왼쪽에 고정하고, 정렬 기준과 방향 선택 도구는 오른쪽 끝에 배치했다. 보기 전환 시 버튼 위치가 바뀌지 않는다. 폭이 부족하면 정렬 도구 묶음이 다음 줄의 오른쪽으로 이동한다. 넓은 목록에서는 기존 열 제목 정렬을 사용하고, 미리보기와 좁은 목록에서는 정렬 선택 도구를 사용한다.

문서를 열어 둔 채 Open file 탐색 화면을 표시할 때 중앙 탐색 영역과 떠 있는 사이드패널의 배경을 불투명하게 해, 뒤의 문서 글자가 파일 목록과 겹쳐 보이지 않도록 했다. All Readable 안에서 문서를 연 경우에도 같은 처리를 적용한다. 탐색기를 닫으면 열어 둔 문서로 돌아오며 문서의 내용과 상태를 유지한다.

기존 미디어 탐색의 반투명 표시, 하단 도구 입력 차단, 파일 선택·체크와 정렬 동작은 유지한다.
