# v0.423.0 — 목록 열 너비와 표시 설정

List 보기의 Columns 메뉴에서 Size, Type, Created, Modified 열의 표시 여부를 선택할 수 있다. Name은 항상 표시한다. 좁은 창의 두 줄 목록도 선택한 정보만 요약에 표시한다.

열 제목 사이의 경계를 끌거나, 경계에 초점을 둔 뒤 좌우 방향키로 너비를 조절한다. 창 크기가 바뀌면 조절한 비율을 바탕으로 목록 폭에 맞춘다. Restore default layout은 열 너비와 표시 여부를 기본값으로 되돌린다.

열 배치는 폴더와 S1/S4 탐색 화면에서 공통으로 사용한다. 폴더별 Preview/List 보기와 정렬 설정, 선택·체크·이름 바꾸기·목록 위치 복원은 유지한다. 숨긴 열도 오른쪽 정렬 메뉴에서 정렬 기준으로 선택할 수 있다.

일반 설치판은 열 설정을 저장한다. Standalone은 기존 설정 비저장 정책에 따라 실행 중에만 유지한다.
