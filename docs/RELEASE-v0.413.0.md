# v0.413.0 — 문서 편집·탐색기 검색·아이콘 개선

- 문서 편집기의 좌우 여백과 본문·줄번호·문단 기호·EOF의 줄 위치를 맞췄다. 편집 모드의 본문 영역은 검정 배경과 흰 글자로 표시하며 Windows 대체 편집기의 장식 색상도 본문과 동기화한다.
- 탐색기 하단 검색창에서 파일명에 포함된 단어로 목록을 좁힐 수 있다. 목록에서 문자를 입력하면 Windows 방식으로 해당 이름을 선택하며 같은 문자를 반복하면 다음 일치 항목으로 이동한다. 필터 해제 시 기존 목록과 체크 상태를 복원하고 폴더 이동 시 검색을 초기화한다.
- 문서 본문에 포커스가 있어도 F11과 F12로 좌우 패널을 전환할 수 있다. Document와 AllReadable의 문서에 적용한다.
- 승인된 줄번호·가이드, 이퀄라이저, 곡선 음파 아이콘을 적용했다. 선택·비활성·음소거 상태의 색상과 복귀 동작을 확인했다.

기본 편집기의 실제 정렬·배경, 대체 편집기 색상, 파일명 필터·선택·체크 복원, 6개 파일 모듈의 하단 배치와 밝고 어두운 테마의 아이콘을 검수했다. 관련 단위 시험, 편집기 protocol/visual 회귀, 구성별 빌드는 통과했다. 정식 배포 절차는 전체 솔루션 시험과 설치·시작·Standalone 검사를 수행한다.

검수 중 좁은 Light 보기 모드의 더보기 메뉴가 열리지 않은 관찰이 있다. 편집 복귀 시 정상이며 제품 원인과 시험용 입력 제한 영향은 아직 분리하지 못했다. 넓은 창의 비활성 아이콘은 별도로 확인했다. 이번 변경은 녹화 오류 수정이나 녹화 기능 배포를 포함하지 않는다.

상세 검수 범위와 한계는 [A413–A415 기록](A413-A415-UI-FOLLOWUPS.md)에 남겼다.
