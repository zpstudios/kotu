# v0.418.0 — 목록의 상위 이동 행과 열 제목 정렬

List 보기의 `Up one folder`를 일반 파일·폴더와 같은 가로 행으로 바꿨다. 아이콘과 이름의 위치, 행 높이를 맞추고 목록 안의 맨 첫 항목으로 표시한다. 정렬을 바꿔도 첫 위치를 유지하며 다른 항목과 함께 스크롤된다. Preview 보기에서는 기존 첫 타일을 유지한다.

넓은 List 보기에서 `Name`, `Size`, `Type`, `Created`, `Modified` 열 제목을 클릭해 정렬 기준을 선택할 수 있다. 같은 열을 다시 클릭하면 오름차순과 내림차순이 바뀌고, 현재 정렬 열에만 방향 화살표가 표시된다. 만든 날짜를 보여 주는 Created 열도 추가했다. 열을 모두 표시하기 어려운 좁은 목록과 Preview 보기에서는 기존 정렬 메뉴를 사용한다.

정렬과 보기 전환 시 선택 및 작업용 체크 상태를 유지한다. 상위 이동은 파일 작업 대상이 되지 않으며, 기존 무채색 아이콘과 테마, 이름 변경, 보기 전환 방식은 유지했다.
