# v0.422.0 — 폴더별 보기와 정렬 기억

탐색기의 Preview/List 보기와 정렬 기준·방향을 폴더별로 기억한다. 다른 폴더를 다녀와도 각 폴더에서 지정한 설정으로 돌아오며, 일반 설치판에서는 앱을 다시 실행한 뒤에도 복원한다.

설정하지 않은 폴더는 Preview와 기존 기본 정렬로 시작한다. 보기 또는 정렬을 처음 변경하면 그 폴더의 보기·정렬을 함께 기억한다. 여러 창에서 같은 폴더의 보기와 정렬을 각각 바꿔도 다른 항목의 저장값을 보존한다.

보기 전환과 정렬 변경 시 기존 선택·체크 및 목록 위치 복원을 유지한다. 폴더를 읽는 도중에는 이전 화면의 변경 요청을 적용하지 않는다.

Standalone은 기존의 설정 비저장 정책에 따라 실행 중에만 폴더 설정을 기억하고, 종료 후에는 저장하지 않는다.
