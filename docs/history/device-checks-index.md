# 실기기 검증 시나리오·관측 색인

현재 검증 범위는 [DEVICE-CHECKS](../DEVICE-CHECKS.md)에서 고른다. 이 파일은 기존 관측과 미확인 시나리오의 주소록이다. 과거 대기 항목은 통과·폐기 처리되지 않았고, 오래된 시험 지시를 현 버전에 무조건 재실행하라는 뜻도 아니다. 관련 변경/재현이 생기면 당시 전제와 지금 동작을 대조하여 필요한 범위만 선택한다.

[정리 전 고정 원문](https://github.com/zpstudios/kotu/blob/070e21af070996ba3d78fb440db9b4552f75a723/docs/DEVICE-CHECKS.md) · 커밋 `070e21af070996ba3d78fb440db9b4552f75a723` · 원래 `docs/DEVICE-CHECKS.md`. 아래 줄 범위를 Git 또는 고정 원문에서 조회한다. 실제 파일/화면을 보지 않은 항목, 합성 probe와 정상 앱 관측, 실패한 시도와 후속 성공을 구분한다. 원문 `artifacts/...`는 당시 근거 위치이며 현재 저장소에 존재함을 보장하지 않는다.
