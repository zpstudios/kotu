# 작업 근거 회수 색인

현재 사양은 기능 문서, 현재 열린 상태는 [요구사항](../REQUIREMENTS.md), 현재 검증 경계는 [실기기 확인](../DEVICE-CHECKS.md)이 정본이다. 여기는 원문을 복사하지 않고 고유한 요구·정정·실패·보호 자료를 회수하는 공용 입구다. 향후 작업도 기존 주제/행을 갱신하며 작업별 장문 보관 문서를 추가하지 않는다.
