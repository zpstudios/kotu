# v0.416.0 — 탐색기 보기와 폴더 작업 개선

중앙 탐색기에 Preview / List 보기와 정렬 도구를 추가했다. 보기와 정렬은 서로 독립적이며, 두 보기에서 검색·선택·체크와 파일 작업을 공유한다. 양쪽 패널이 열리면 미리보기 6열, 한쪽만 열리면 9열, 모두 닫으면 12열이다. 패널 폭과 기존 테마·상위 폴더 아이콘은 유지했다.

왼쪽 패널은 폴더 트리로 정리했다. 폴더를 선택하면 오른쪽에 해당 폴더의 기본 정보를 표시하고, 파일도 경로·종류·날짜·크기·속성·로컬 가용성을 함께 보여 준다. 폴더 크기를 자동으로 재귀 계산하지 않으며, 선택 정보와 열린 문서는 별도로 유지한다.

폴더 메뉴에 Open, Open in Windows Explorer, Copy path, Show details를 추가했다. 기존 Cut / Copy / Paste / Rename / Delete도 유지하며, 체크된 항목과 우클릭한 폴더의 작업 범위를 구분한다. 상위 폴더 항목은 파일 작업과 메뉴 대상에서 제외한다.

검수 범위와 한계는 [A417 구현 기록](A417-EXPLORER-REFRESH.md)을 따른다.
