# v0.417.0 — 미리보기 타일의 선택 표시 개선

Preview 보기에서 일반 선택한 폴더와 파일에 테마 강조색의 2px 테두리를 표시한다. 선택 배경이 텍스트 미리보기 바탕과 비슷해 선택하지 않은 파일까지 선택된 것처럼 보이던 혼동을 줄였다. 스크롤로 타일 컨테이너가 재사용될 때도 현재 선택 상태에 맞춰 테두리를 갱신한다.

일반 선택과 작업용 체크박스의 의미는 그대로다. 미리보기 내용, 이름변경, 상위 폴더 아이콘, 패널 폭과 6/9/12열 배치도 유지했다. 이번 변경은 선택 표시를 보강한 후속 수정이며, Preview/List 전환과 폴더 작업 기능은 이전 v0.416.0에서 제공됐다.
