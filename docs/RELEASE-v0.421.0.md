# v0.421.0 — 미리보기 크기·선택 표시 개선

창이 좁거나 앱의 화면 배율이 높을 때 미리보기 항목끼리 겹치거나 파일명과 체크박스가 잘리던 문제를 고쳤다. 타일 폭에 맞게 항목을 배치하고, 작은 타일에도 파일명과 체크박스가 들어갈 세로 공간을 확보한다.

상위 이동·폴더 아이콘은 자신의 칸이 작을 때만 축소한다. 여유가 있는 화면에서는 기존 아이콘 크기와 타일 높이를 유지한다.

List에서 Preview로 돌아오거나 선택 항목을 화면 밖으로 스크롤했다가 다시 표시할 때, 선택은 유지되지만 선택 테두리가 나타나지 않던 문제도 보완했다. 보기 복원과 미리보기 항목의 재사용 뒤 테두리를 현재 선택 상태에 맞춘다.

상위 이동의 첫 위치, 6·9·12열 배치, Preview/List 전환과 왼쪽 보기·오른쪽 정렬 도구, 선택·체크·이름 바꾸기·스크롤 동작을 유지한다.
