# A86 키 동작 표 — 초안 v1 (2026-08-13, 사용자 합의 대기)

> A86 착수의 선행 조건(부록 B 36·48·49). 재료: A58 동작 체계 + A86(Z/X·Enter 일괄 토글·경계 버튼)
> + A90(Esc·오픈 파일) + A98(휠) + A34 키 맵 + A84(Shift+N·Ctrl+S).
> **굵은 글씨 = 제안값(미확정)** — 쟁점 Q1~Q9로 O/X를 받는다. 확정되면 이 표가 REQUIREMENTS A86
> 본문과 A87 단축키 장으로 승격된다.

## 상태 정의

| 상태 | 설명 |
| --- | --- |
| S1 | 탐색기 상태 — 콘텐츠 없음, 3구획(A93) 도크 표시 |
| S2 | 콘텐츠 열림 + 좌/우 전부 닫힘 |
| S3 | 콘텐츠 열림 + 좌/우 일부·전부 떠 있음(반투명이든 도크든) |
| S4 | A90 반투명 4구획 — 콘텐츠 위에 '오픈 파일'로 띄운 상태 |

포커스 예외(상태와 무관하게 우선): **F1 텍스트 입력**(문서 에디터·이름변경 — 문자 키는 전부 입력으로),
**F2 리스트/트리/썸네일 포커스**(타이핑 탐색 활성).

## 포커스 예외 규칙 (제안)

- **F1 텍스트 입력**: Z·X·Enter·문자 핫키 전부 **입력 우선**(A32·A34 통과 규칙 재사용). Esc만 통과.
- **F2 리스트/트리/썸네일 포커스**: **Z/X는 타이핑 탐색(첫 글자 점프)이 우선 — 오버레이 여닫기는
  Enter·경계 버튼·마우스로 (Q4)**. 반대안: Z/X를 오버레이 우선으로 하고 타이핑 탐색에서 z·x만 희생.

## 안전장치 정리 (제안)

- Alt의 OS 메뉴 모드 회피 로직: **제거** — Z/X는 문자 키라 불필요 (Q6).
- 홀드 취소 트리거(다른 키·클릭·휠 개입 시 홀드 해제): **유지** — Ctrl+휠 줌 개입도 취소로 취급 (Q6).
- Enter "다시 살아나기"의 복원 대상: **세션 내 직전 구성, 없으면 A81 기본 도크 (Q3)**.

## 쟁점 — O/X로 답받을 것

| # | 제안 | 반대안 |
| --- | --- | --- |
| Q1 | Enter 원 기능 = 탐색기 선택 열기 / 비디오 전체화면 / 에디터 줄바꿈. **그 외 전부 일괄 토글** | 원 기능 목록을 더 넓게/좁게 |
| Q2 | 비디오에서 일괄 토글은 Z/X·경계 버튼으로 충분(Enter는 전체화면 양보) | 비디오만 다른 키(예: Shift+Enter)로 일괄 토글 |
| Q3 | Enter 재호출 = 직전 구성 복원(없으면 A81 기본) | 항상 A81 기본 구성으로 |
| Q4 | 리스트 포커스에서 Z/X = 타이핑 탐색 우선 | Z/X = 오버레이 우선 |
| Q5 | 4구획(A90) 중 Z/X·핫키 무시 — 4구획은 한 몸(Esc/재누름/오픈 버튼만) | 4구획에서도 Z/X 개별 조작 허용 |
| Q6 | Alt 회피 제거 + 홀드 취소(키·클릭·휠) 유지 | 홀드 취소도 손질 |
| Q7 | 경계 버튼 클릭 = 불투명 도크 토글(2연타와 같은 상태) | 반투명 고정 상태로 열기 |
| Q8 | S3에서 Esc 무동작(복귀는 S4 전용 개념 — 사용자 지시 "엄연히 다름" 반영) | S3에서도 Esc = 전부 닫기 |
| Q9 | 트레이 3자 표기: IMG/VID/AUD/DOC/**ARC**/ALL + 유휴 1줄·저채도 vs 열림 2줄·모듈 색 | Archive 풀네임 등 |
| Q10 | S3(오버레이 일부 존재)에서 '오픈 파일' = 그대로 4구획 반투명 진입 | 먼저 기존 오버레이 정리 후 진입 |
