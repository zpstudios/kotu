# KOTU 실기기 확인 — 현재 경계와 필요한 다음 검증

현재 제품 버전과 선택된 작업은 [HANDOVER](HANDOVER.md)를 따른다. 이 파일은 아직 결론을 넓힐 수 없는 검증 범위의 정본이며 날짜별 시험일지가 아니다. 아래 미확인은 통과·결함 확정을 뜻하지 않는다. 사용자가 보류한 녹음·녹화/빠른 녹음은 재개 승인 전 실행하지 않는다. 실제 앱 화면 확인·조작은 [공식 절차의 승인·분리·복원 기준](development/official-release-and-install.md)을 따른다.

선택된 변경과 관련된 검증만 묶어서 수행한다. 외형 변경은 실제 화면을 확인하고, 저장·IME·녹음/녹화·네이티브 재생·장치 수명은 해당 동작의 실제 검증 필요성을 따로 판단한다. 정적 검사·합성 provider·격리 probe를 정상 앱·실제 입력·물리 장치 성공으로 바꾸지 않는다. 공식 자산/설치본의 해시 대조는 계속 수행하되 긴 해시 목록을 이 문서에 반복하지 않는다.

최근 정정·실패·복원 근거는 [공유 근거 색인](history/evidence-index.md), 더 오래된 상세는 [실기기 시나리오·관측 색인](history/device-checks-index.md)의 주제/버전/고정 Git 줄 위치에서 찾는다. v0.161.0 이하와 A170은 사용자 결정에 따른 [미확인 종결](history/device-checks-closed-unverified.md)이며 통과가 아니다. 이후 오래된 미확인도 임의로 종결하지 않는다. 과거 `artifacts/...` 주소는 당시 근거 위치이며 현재 저장소에 파일이 있다고 가정하지 않는다.

## 결과를 갱신할 때

[완료·인계 정리 절차](development/maintenance-notes.md#document-lifecycle)에 따라 해당 범위의 행을 덮어쓴다. 미관측·보류를 통과로 바꾸지 않으며, 결함은 기존 A번호와 대조한다. 실제 샘플·저장/복구 보존본은 문서 정리 대상이 아니다.
