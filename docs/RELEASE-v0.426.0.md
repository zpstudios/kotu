# v0.426.0 — PNG/TIFF 방향 보정과 APNG 재생

방향 정보가 있는 PNG 사진을 올바른 방향으로 표시하고, 수동 회전·복사·인쇄에도 같은 방향을 적용한다. 로컬 PNG/TIFF 썸네일도 사진의 회전·반전 정보를 반영한다. 원본 파일은 변경하지 않으며 클라우드 전용 파일의 썸네일을 위해 원본을 내려받지 않는다.

APNG를 `.png`와 `.apng` 확장자로 열어 재생할 수 있다. 모든 프레임에 방향 보정을 적용하고 프레임 간격·반복 횟수·투명 영역 합성을 유지한다. 썸네일·복사·인쇄는 첫 애니메이션 프레임을 사용한다. 다른 파일로 이동하거나 뷰를 닫으면 이전 재생을 종료한다.

앞서 로컬 검수를 마친 녹화 저장 안정화, 준비되지 않은 검은 녹화 프레임 방지, 편집 중 Alt+Enter 전체 화면 전환 보완도 이번 배포에 포함한다.
