배치4는 정보 우선순위·빠른 선택 전환·합성 가용성 실패·취소·수명을 확인했다. 배치5 최종본은 상위 행11개 마우스/키보드 사례, Preview/List·S1/S4 메뉴, 체크 복수 복사, S4 정보 배치 보존을 확인했다. 동일 명령 소스의 앞선 검수에서 선택 복사·이동·이름변경·삭제·실제 Windows Explorer 열기도 확인했다. 각 실행 뒤 설정·레지스트리·시험 파일·클립보드와 감시 종료를 별도로 대조했다.

배치6 기본본은 전체 솔루션 1,145개 시험, 구조·배포·편집기 검사와 실제 COM 전달 검사를 통과했다. 새 폴더·파일의 이름 충돌, 복사 취소/건너뛰기/둘 다 유지, 잘라내기 건너뛰기/대체를 실제 화면에서 확인했다. 사용자가 Preview와 List 각각에서 일반 선택 두 항목 및 체크 두 항목의 드래그를 수행했고, 두 항목 이동과 상위 폴더 항목의 드롭 거부를 확인했다. 메인은 실제 이벤트와 파일의 내용·생성/수정시각, 예상한 추가·제거 경로를 독립 대조했다. 이는 같은 볼륨의 기본 이동 검수이며, 보조키를 누른 드래그까지 포함하지 않는다.

통합 화면 검수에서 작은 오디오 타일의 확장자와 요약이 겹치는 문제를 발견했다. 첫 수정은 실제 글자 잘림으로 거절했다. 최종 수정은 부모 타일의 가용 폭을 사용하고 확장자와 요약을 두 행으로 맞춘다. 다크·라이트의 S1/S4에서 일반 크기와 78/79 DIP 타일을 실제 검수했다. 정상 폭에서는 전체 요약이 보이며 좁은 폭에서는 말줄임과 전체 툴팁을 유지한다. 45 DIP에서는 겹침과 영역 이탈이 없었지만 가독성을 보장하지 않는다. 보기 왕복과 이름변경 취소 뒤에도 표시·선택·체크가 유지됐다.

사용자의 직접 한글 입력과 조합 범위 이벤트를 함께 확인했다. 활성 조합 구간에는 필터를 예약하거나 적용하지 않았고, 입력기가 종료를 알린 뒤 가나 필터를 적용했다. Enter 당시 조합은 종료되어 기존 동작대로 목록의 상위 폴더로 키보드 포커스가 이동했다. 활성 조합 중 Enter/Escape까지 검수한 것은 아니다. 최종 오디오 수정의 App 빌드·집중 구조 검사는 통과했으며, 전체 1,145개 시험은 변경 없는 영역의 직전 배치 근거다. 최종 커밋은 원격 두 빌드에서 전체 시험을 다시 수행해 각각 1,145개를 통과했다.

## 근거의 한계

- 합성 속성·실패·지연 시험은 실제 OneDrive 공급자, 실제 접근제어 오류, 모든 OS 경합의 증명이 아니다. 마지막 확인과 실제 파일 작업 사이의 OS 경합 가능성은 남는다.
- 한글 문자열 입력과 실제 IME 조합은 별도로 판정한다. 앱 화면 배율과 Windows 모니터 DPI를 구분한다.
- 계측 실행본의 결과를 최종 배포 실행본 또는 모든 환경의 성능 보장으로 확대하지 않는다. 일시적인 캡처 실패와 초기 클립보드 복원 실패도 숨기지 않고, 복구 후 새 기준선과 성공 여부를 기록했다.
- 로컬 증거는 작업 사본의 artifacts/a417-implementation-20261105 아래에 보관하며 저장소에는 포함하지 않는다. 배치5 수락 정본은 main-review/batch5-final-review.json이다. 배치3 일부 구조 보고서는 재구성본이며 원본 바이트 동일성을 주장하지 않는다.

로컬 최종 수락 정본은 main-review/batch6-final-review.json이다. 다크 실행 중 사용자 입력을 기다리는 구간에 사용자 설정 파일이 별도로 변경된 시각을 발견했으며 작성 주체는 확인되지 않았다. 과거 값으로 덮어쓰지 않고 현재 값을 보존했고, 이후 라이트 실행은 새 기준선과 설정·레지스트리·시험 파일이 일치했다. 전체 실행 동안 설정이 한 번도 바뀌지 않았다고 주장하지 않는다. 최종 배포 실행본은 private 계측을 제거해 다시 빌드하고, 컴파일 입력·어셈블리 메타데이터·시작·정상 종료를 별도로 확인했다.


## 최종 배포 검증

정확한 제품 커밋을 계측 없이 Rebuild/Publish한 로컬 Standalone 실행본도 별도로 확인했다. 12개 제품 어셈블리의 버전·커밋 및 21개 실제 컴파일 명령을 대조해 private 계측0을 확인했고, 컴파일된 Standalone 정책은 true였다. 문서 열기·S4/문서/S1 복귀·AllReadable의 두 오디오 표시·정상 종료를 실제 관찰했다. 종료 뒤 사용자 설정·331개 읽기 가능한 레지스트리 키·합성 파일6항목이 그대로였고 실행본1,067파일과 수락 소스47파일도 일치했다. 첫 로컬 빌드는 복원 단계에서 종료되어 실패 기록을 보존했고 두 번째 빌드는 경고0/오류0으로 완료했다. 로컬 설치 검사는 하지 않았으며 정식 단일 실행 파일 및 설치본 검증은 릴리스 CI 근거다.

최종 정본은 main-review/final-release-review.json과 final-production-ui/final-review.json이다. 일반 build의 master 경로는 작업 브랜치용 패키지·설치 단계를 생략하고, release가 실제 배포 패키지와 설치본을 검증했다.
