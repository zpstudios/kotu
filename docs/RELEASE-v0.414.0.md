# v0.414.0 — 탐색기 체크·상위 폴더·패널 배치 개선

- 중앙 탐색기의 현재 파일에서 Space를 누르면 파일 작업용 체크가 켜지거나 꺼진다. 다른 항목으로 이동해도 기존 체크를 유지하며 왼쪽 목록과 동기화한다. 검색창에서 입력하는 공백은 그대로 유지한다.
- `Up one folder`가 첫 번째 타일 자리에 표시된다. 클릭 또는 Enter로 한 단계 올라가며, 빈 폴더나 검색 결과가 없어도 남는다. 파일 선택·체크·일괄 작업에는 포함되지 않는다.
- 파일을 연 뒤 Esc로 탐색기에 돌아오거나 사이드바·모듈·창 크기가 바뀔 때 실제로 표시된 패널에 맞춰 중앙 폭과 4/6/8열을 다시 맞춘다. 타일이 사이드바 아래에 가려지는 문제를 수정했다.
- 폴더 이동으로 타일이 교체될 때 중앙 탐색기가 가진 입력 위치를 유지해 Ctrl+F 검색을 이어갈 수 있다.

실제 독립 실행 앱에서 양쪽·한쪽·닫힌 패널, 반복 열기/복귀, 최대화/복원, S4 두 보기 모드, Hardware/Document/Image 전환, 빈 폴더와 검색, 체크 동기화 및 상위 타일 키보드 동작을 검수했다. Core 468개 시험과 구조 검사 20개, 정규 앱 빌드는 통과했다. 정식 배포의 전체 시험·시작·설치·Standalone 검사는 배포 절차에서 별도로 확인한다.

물리적으로 Space를 길게 누르는 시험, 실제 IME 조합, 루트 드라이브의 비활성 타일과 드래그 작업은 이번 실제 UI 검수 범위에 포함하지 않았다. 상세 근거와 한계는 [A416 검수 기록](A416-EXPLORER-SELECTION-LAYOUT.md)에 남겼다. 녹화 보류 작업은 이번 배포에 포함하지 않는다.
