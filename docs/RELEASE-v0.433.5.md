# v0.433.5 — 디자인별 타일과 조작부 외형 조정

Folded paper를 제외한 10개 디자인의 파일 타일을 미리보기 느낌에 맞게 다듬었습니다. 일반 항목의 불필요한 면과 테두리를 줄이고, 선택·체크 상태를 디자인에 맞게 표시합니다. Bold frames의 상시 프레임은 유지합니다.

Solid pictograms의 선택 타일에는 강조색 배경과 배경에 대비되는 파일명·폴더 아이콘을 함께 적용합니다. Editorial typography와 Terminal console의 버튼 색, 나머지 디자인의 체크 표시도 미리보기와 맞췄습니다.

기존 트리 줄 간격, 버튼 크기, 타일 크기·배치, 패널 비율과 보기 모드는 유지합니다. 이미 적용된 아이콘 모양·글꼴 계열과 Folded paper 외형도 그대로 사용합니다.
