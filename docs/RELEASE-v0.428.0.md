# v0.428.0 — 정식판과 함께 설치하는 KOTU Test

이 버전부터 작업 브랜치의 테스트 Setup은 Windows에 **KOTU Test**로 설치된다. 정식 KOTU와 설치 폴더·설정을 따로 사용하므로 두 앱을 함께 실행할 수 있다. 테스트판을 설치하거나 제거해도 정식 KOTU는 기존 버전에서 다음 GitHub 업데이트를 받을 수 있다.

정식판에서 웹 업데이트를 확인하려면 **Settings → Updates**를 연다. 테스트판은 새 테스트 Setup으로 갱신한다. 이전 방식으로 만든 테스트 Setup에는 이번 분리가 적용되지 않는다.
