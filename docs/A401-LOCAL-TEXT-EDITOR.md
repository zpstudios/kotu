# A401 — 큰 문서의 연속 입력을 위한 로컬 텍스트 편집기

## 범위와 상태

v0.412.0/f0344ec로 2026-10-31 11:55:39 KST에 정식 배포했다. 약100만 자 시험 문서에서 이전 스냅샷 재사용 수정본은 여전히 느리다는 사용자 확인을 받았고, 이번 정상 수정본에서는 2026-10-31 사용자가 **“입력이 밀리지 않음”**이라고 답했다. 이는 해당 문서의 실제 키보드 체감 확인이며 모든 파일·입력 방식의 지연 수치로 일반화하지 않는다. 배포 결과와 현재 작업 상태는 `HANDOVER.md`가 정본이다.

설치형·Portable의 일반 텍스트 편집 표면을 기존 WebView2 안의 로컬 Monaco Editor로 연결한다. Standalone, 기존 상한/잘림 정책, 초기화 실패 시의 기존 편집기 대체 경로는 유지한다. PDF와 원본 레이아웃을 렌더하는 기능은 이 변경의 대상이 아니다. 기존 A401 장식·검색 개선 이력은 `A401-VISUAL-LINE-SEARCH.md`를 참조한다.

실제 한국어 IME 조합·연속 입력/스크롤의 체감 지연은 원격 데스크톱 검수로 수락하지 않는다. Unicode 문자열 입력·저장을 IME 시험으로 세지 않는다. light/high-contrast·다른 DPI·고빈도 휠/held-key·극단적으로 긴 줄과 초기화 실패 대체 경로도 이번 실제 UI 범위 밖이다. 본문에서 Ctrl+O는 탐색 화면을 열지 않았고 파일 열기 버튼으로 검수했으며, Ctrl+O는 이번 단축키 통과 항목에 포함하지 않는다. A401 전체 완료로 표시하지 않는다. 우선순위 1번 녹음·녹화 실기기 검수는 사용자의 지시로 보류한다.

## 확인한 지연과 수정 방향

사람이 실제 지연을 재현한 위치는 원본의 offset622361, 논리6285:1이었다. 원본에 LF6개만 추가된 것을 저장본으로 확인했다. 기존 편집기의 매 Enter에서 Preview→TextChanging은205.02–207.30ms였고, 자동6회 입력에서는 UI CPU1296.875ms / wall1309.05ms로 계산 작업이 대부분을 차지했다. 공식 PDB가 WinUIEdit 줄 배치와 TextShaping/DWrite 실행을 확인했다. NoWrap은 개선이 없었고 문서 높이 알림을 원인으로 단정하지 않았다.

관리 코드의 중복 스냅샷 읽기를 줄이는 이전 수정은 전문 읽기·할당을 줄였지만 사용자의 입력 밀림을 해결하지 못했다. 이번에는 기존 편집기의 해당 입력 경로를 새 편집 표면으로 교체했다. 이전/이후 측정은 이벤트 경계와 창 크기 등이 달라 물리 키 지연 배속비를 제시하지 않는다.

## 본문·저장·수명 계약

- 관리형 버퍼는 LF/UTF16 기준이며 편집 세션과 연속 버전을 검사한다. 변경은 원본 좌표 내림차순의 델타로 원자적으로 반영한다. 큰 메시지는 크기를 제한한 프레임으로 나누고 서로게이트 쌍을 보존한다.
- Windows에서 빈 문서·한 줄 문서의 CRLF→LF 정리가 Monaco 내부 초기 버전을 올리는 경우가 있다. 정리 직후 버전을 기준으로 호스트와 통신하는 버전을1부터 맞추며 Undo/Redo 동안 기준을 바꾸지 않는다. 엄격한 연속 변경·본문 일치 검사는 유지한다.
- 저장은 대기 중인 편집을 받은 뒤 본문 스냅샷을 대조한다. 닫기는 읽기 전용 전환·스냅샷 확인과 소유권이 있는 동결을 거친다. 호출자의 실제 전환이 끝나기 전까지 승인을 유지하고, 취소하면 원래 편집을 재개한다.
- 임시 Unloaded는 같은 모델과 Undo를 보존한다. 명시적인 콘텐츠 해제만 모델·WebView를 종료한다. 승인 후 자식 콘텐츠가 바뀌면 이전 소유권이 새 문서를 건드리지 않는다.
- 편집이 활성화된 뒤의 실패는 본문을 조용히 기존 편집기로 바꾸지 않는다. 받은 본문을 명시적으로 복구하는 경로를 제공한다.

## 기존 기능 연결

검색·치환은 현재 편집 표면의 본문과 선택을 사용한다. 오래된 검색 응답이 사용자의 새 선택을 덮지 않도록 요청·선택 세대를 확인한다. Ctrl+F/H, F3/Shift+F3, Escape와 본문 포커스 복귀를 연결한다.

표준 키보드 복사/붙여넣기/Undo는 브라우저의 기본 입력 경로를 사용한다. 우클릭 메뉴 명령은 버전·선택 표를 대조하고 순서를 유지한다. 메뉴 붙여넣기 직후 저장/보기/닫기가 들어와도 해당 붙여넣기가 먼저 반영된다. IME 조합 중에는 모드를 강제로 전환하거나 조합을 확정하지 않는다.

보기 전환과 Markdown/HTML 미리보기는 최신 미저장 본문을 사용한다. 검색창에 포커스가 저절로 옮겨졌다는 이유만으로 렌더된 문서를 소스로 바꾸지 않는다. 명시적 검색 명령과 실제 검색어 입력은 기존 소스 검색 동작을 유지한다. 인쇄는 준비한 실제 문서 제공자를 고정한다.

가이드·문단 기호·거터는 화면 안의 제한된 범위만 계산한다. 확대20–500%는 같은 앱 확대 값에서 파생하며 작은 배율의 좌표·선택도 보정한다. 상태 통지는 프레임마다 합치지만 본문 델타와 버전 메시지 순서는 합치지 않는다.

## 로컬 자산

Monaco0.52.2와 자산 생성 도구 esbuild0.25.11을 고정한다. `EditorSource/source-lock.json`의 원본 아카이브 해시를 대조하며 설치 스크립트를 실행하지 않는다. 생성한 `VirtualEditor` 자산과 원본 라이선스를 앱에 동봉한다. 편집기 실행은 외부 서버나 인터넷 연결을 요구하지 않는다. 고지는 루트 `THIRD-PARTY-NOTICES.md`와 배포본의 해당 라이선스 파일을 참조한다.

## 검증 결과와 남은 범위

초기 전체963개 시험과 이후 수정별 집중 시험, 브라우저 프로토콜·시각 계산 시험을 통과했다. 최종 B3e는 버퍼 시험13개와 재현 가능한 자산 생성, 정상 빌드/publish를 검증했다. 메인은57개 소스·1065개 패키지 파일·15개 빌드/배포 바이너리·8개 자산을 독립 대조했다. 보류 중인 녹화 변경은 이 배포 대상에 포함하지 않는다.

최종 제품 커밋의 GitHub 일반 빌드41161508569와 릴리스41161508653는 각각963/963·8개 시험 어셈블리·컴파일 경고0/오류0으로 attempt1 통과했다. COM·실행본 시작·설치·Standalone 검사와 정확한 태그·자산8개·Latest도 확인했다. 로컬 초기 시험과 별개로 최종 배포 소스의 전체 시험을 확인한 결과다.

일반 build와 release에서도 Node24로 프로토콜·시각 계산 시험을 각각 실행한다. 두 시험은 npm 설치나 자산 재생성 없이 실행하며, 앞 시험의 실패가 뒤 시험의 성공에 가려지지 않도록 단계를 분리한다. 배포 검사 계약은 양쪽 workflow에서 누락·순서 변경·조건 우회·실패 무시를 거부한다. 기존7개와 새24개 우회 회귀, 구조 검사와 actionlint를 검수했다.

실제 정상 후보에서 확인한 항목:

- 같은 큰 문서의6회·36회 연속 Enter, 정확한 줄 추가·저장·Undo/Redo와 이후 추가 줄 증가가 없는 상태.
- 최종 후보6회도 정확한6LF와 Undo 원본 복원. 도구 호출 구간은534.156ms였고 물리 키 입력 지연으로 해석하지 않는다.
- 검색·치환, 키보드 선택/복사/여러 줄 붙여넣기, 검색 Escape 후 실제 방향키 이동, 우클릭 Copy 후 이동과 Paste→즉시 Save 순서.
- 최신 미저장 Markdown/HTML 미리보기, Undo 저장, 빈 문서와 한 줄 문서의 새 편집기 초기화.
- 사용자의 실제 연속 Enter 시험에서 입력이 밀리지 않는다는 확인.

2026-10-31 당시 실제 한국어 IME는 자동 조작 도구의 한/영 키 미지원으로 확인하지 못했다. Unicode 붙여넣기를 IME 시험으로 세지 않는다. 당시 미확인이던 최종20/40% 선택·인쇄 미리보기 취소·새 문서 자동 포커스·상한 초과 보호는 위2026-11-14 후속에서 확인했다. 앞선40% 마우스 선택·비활성 선택 표시는 통과했으며100% 한글 화면의 JPEG 캡처 충실도는 판단을 보류한다. light/high-contrast 실제 화면과 IME는 여전히 잔여다.

로컬 상세 근거는 `artifacts/a401-editor-integration-20261031/`의 메인 검수와 배치별 evidence에 있다. 이 디렉터리는 Git에 없으므로 다른 PC에서 근거를 재확인한 것으로 주장하지 않는다. A401 전체의 스크롤·극단 조건 검증 완료를 뜻하지 않는다.
