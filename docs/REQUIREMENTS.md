# ZP 요구사항 정리 (초안)

> 사용자 메모(키워드)를 정리한 초안 — **아직 반영 계획 아님**. 직접 수정·다듬은 뒤 확정 예정.
>
> 상태 표기:
> - `[완료]` 이미 반영됨 (참고 버전 명기)
> - `[부분]` 일부만 반영 — 남은 부분 명시
> - `[미반영]` 아직 안 함 (확정되면 할 일)
> - `[질문]` 의미가 불명확해서 확인 필요
> - `[폐기?]` 이후 지시로 대체됐거나 지금은 무의미해 보임 — 삭제 여부 확인

- [미반영] 리스트 위 필터(파일 종류) 체크박스.

- [부분] Alt 우측 리스트가 줌(Zoom) 화면공유에서 안 보이는 문제 — 원인 미확인, 2연타 고정으로 우회 가능한지 실기기 확인 대기.
