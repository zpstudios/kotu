# ZP 요구사항 — 남은 작업 정리

> **운용 규칙**
> 1. "~~~ 구현/수정해줘" 요청은 이 문서에 항목 추가만 한다 (실개발 X).
> 2. 실제 개발은 "미반영 A?? 진행" 지시가 있을 때만 착수한다.
> 3. **A번호는 영구 ID** — 재정렬·재사용 금지. 완료되면 문서에서 항목을 제거하고 그 번호는 결번 처리. 신규 항목은 마지막 번호 다음을 부여.
>
> 상태 표기:
> - `[미반영 An]` 아직 안 함 — 지시가 오면 착수 (부록 A 번호)
> - `[확인]` 구현은 됐으나 실기기 확인/재등록 확인이 남음
> - `[보류]` 후순위 (조사·선행 작업 필요)

  - 구현 메모: 드라이브 종류는 WMI(MSFT_PhysicalDisk MediaType/BusType)로 조회 — DriveInfo만으로는 SSD/HDD 구분 불가.
- [미반영 A27] **하단 바 버튼 통일**: ① 테두리·배경 스타일 통일(메뉴 버튼·열기 버튼 등 제각각인 외곽선 정리)
  ② 상하 정렬 전부 수직 중앙 ③ 크기는 **딱 2종** — 1칸(재생·볼륨·열기·메뉴 등) / 2칸(Fit·재생속도·리프레시 주기 등).
- [미반영 A34] **모든 버튼류에 핫키 부여**(가능한 범위): 지금 안 걸린 버튼들(Rotate 외 이미지 버튼, 배속, 자막,
  압축 Extract 등)에 단축키 지정 + 툴팁에 표기. 키 맵은 구현 시 충돌 검토해 확정.
- [미반영 A40] **창을 작게 줄여도 하단 바는 유지**: 수동 리사이즈로 창이 작아질 때 하단 바가 잘리거나 사라지지 않게.
  구현: 창 최소 크기 강제(하단 바 44px + 최소 콘텐츠 확보, OverlappedPresenter.PreferredMinimumHeight/Width 또는
  WM_GETMINMAXINFO) + 하단 바 내용이 좁아지면 우선순위 낮은 요소부터 축약/생략(정보 텍스트 → 아이콘만).
- [미반영 A41] **UI 배율 라이브 조절**: **Ctrl + +/−** 및 **Ctrl + 마우스 휠**로 UI 스케일(UiScale)을 즉석에서 조절.
  단계는 설정 Display의 배율 목록을 따르고, 변경 시 설정에 저장(모든 창 즉시 반영). Ctrl+0 이 Settings 단축키와
  겹치므로 배율 초기화 키는 별도 지정(예: Ctrl+*). ※ 이미지 줌(Ctrl+휠)·영상 볼륨 휠과의 충돌 정리 필요 —
  모듈 콘텐츠 위에서는 기존 동작 유지, 하단 바·빈 영역에서만 배율 조절 등의 규칙을 구현 시 확정.
- [미반영 A43] **진짜 포터블 단일 파일 실행본** (설치본과 별개 배포물):
  - 현행 zip 방식의 한계(사용자 판단): 레지스트리 등록은 없어 "미설치"이긴 하나, 받아서 실행하면 압축이
    풀린 뒤 쓰는 방식이고 자동 업데이트·설정 저장이 설치본과 동일하게 동작함.
  - 요구 3가지: ① **단일 파일인 채로 바로 실행** (수동 압축 해제 없이 exe 하나)
    ② **자동 업데이트 대상 아님** (업데이트 체크·알림·적용 전부 비활성)
    ③ **완전 스탠드얼론 — 설정값 저장도 안 함** (%AppData%·레지스트리 등 시스템에 흔적 남기지 않기.
    설정은 세션 한정 메모리 유지 또는 기본값 고정 — 구현 시 확정)
  - 구현 아이디어(사용자 제안): 외부 라이브러리 사용권 요구사항 때문에 물리적 단일 파일이 어렵다면,
    **실행 시점에 임시/가상 공간에 자체 압축 해제 후 실행**하는 방식 검토.
  - 구현 시 조사할 것: .NET single-file publish의 네이티브 라이브러리 자체 추출
    (IncludeNativeLibrariesForSelfExtract — 임시 폴더 추출이라 사용자 제안과 같은 계열),
    libvlc처럼 플러그인 디렉터리 구조를 요구하는 네이티브 의존성 처리, WinUI 3 unpackaged
    single-file 지원 여부, MPL-2.0(LHM 계열)·LGPL(libvlc) 고지 파일 동봉 방법(추출물에 포함 등),
    포터블 모드 감지 방법(빌드 분기 vs 실행 시 판별), 임시 추출 잔여물 정리 정책.
