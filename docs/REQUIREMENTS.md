# ZP 요구사항 — 남은 작업 정리

> **운용 규칙**
> 1. "~~~ 구현/수정해줘" 요청은 이 문서에 항목 추가만 한다 (실개발 X).
> 2. 실제 개발은 "미반영 A?? 진행" 지시가 있을 때만 착수한다.
> 3. **A번호는 영구 ID** — 재정렬·재사용 금지. 완료되면 문서에서 항목을 제거하고 그 번호는 결번 처리. 신규 항목은 마지막 번호 다음을 부여.
>
> 상태 표기:
> - `[미반영 An]` 아직 안 함 — 지시가 오면 착수 (부록 A 번호)
> - `[확인]` 구현은 됐으나 실기기 확인/재등록 확인이 남음
> - `[보류]` 후순위 (조사·선행 작업 필요)

---

## 1. 셸 · 시작 메뉴

- [미반영 A1] 메뉴 항목 hover 단축키 힌트: 지금은 즉시 표시 → 다른 버튼 툴팁처럼 **약 1초 지연 후** 표시 + 표시 모양도 툴팁 스타일로.
- [미반영 A2] 인스턴스별 색깔 구분 + 번호(1~9) 표시. 2번째 창이 뜨는 순간 첫 창에도 1번 표시. 중간 창이 닫히면 번호 당겨오기(재번호 규칙은 구현 시 확정).
- [미반영 A3] 앱(창) 아이콘 구성 반전: **메인 표식 = 모듈 식별 글씨, 작은 표식 = zp** (현재는 ZP 글자가 메인, 색으로만 모듈 구분).
- [미반영 A24] **같은 모듈 다중 인스턴스 + 새 창 열기** (신규): 현재는 다른 모듈 파일을 열 때만 창이 늘고,
  같은 모듈은 기존 창을 재사용해 같은 모듈 창 2개가 불가능. 추가할 것 —
  ① 명시적 "새 창" 수단(예: Ctrl+N, 메뉴 항목), ② 같은 모듈 파일을 새 창으로 여는 방법(예: Shift+더블클릭 or 옵션),
  ③ 창 재사용 규칙을 설정으로 선택(항상 재사용 / 항상 새 창). A2 번호 배지와 자연 연동.
- [미반영 A23] **확장자별 파일 아이콘** (신규): ZP에 연결된 확장자는 탐색기 파일 아이콘도 ZP 것으로 표시하되,
  - 아이콘 중앙에 **해당 확장자 텍스트를 크게** (지금의 "ZP" 글자 스타일처럼. 예: 7Z, RAR, TAR, MP4, JPG, TXT…)
  - **우측 하단에 작게 "ZP"** (ZP 앱 연결 표시)
  - 배경/색상은 **소속 모듈 고유 색** (zip=amber, image=green, video=red, doc=purple, …)
  - 전 모듈 담당 확장자 대상 — 확장자 수만큼 .ico 생성(스크립트) + 파일 연결 등록 시 확장자별 DefaultIcon 지정.

## 2. 내장 탐색기 · 오버레이

- [미반영 A5] 우측 리스트 정렬: 이름 / 크기 / 수정일 순 전환.
- [미반영 A6] 리스트 뷰 컬럼: 파일명 + 길이(재생시간, 미디어만) + 용량.
- [미반영 A7] 리스트 위 필터(파일 종류) 체크박스.
- [미반영 A8] 현재 경로 표시(우측 리스트 쪽).
- [확인] 오버레이 반투명(아크릴, v0.31.0) — 실기기 확인 대기. 비디오 표면(스왑체인) 위에서 안 비칠 가능성.
- [확인] Alt 우측 리스트가 줌(Zoom) 화면공유에서 안 보임 — 2연타 고정(v0.32.0)으로 우회 가능한지 확인.
- [보류 A4] 자체 탐색기 유지 확정. 파일 읽기/쓰기 권한(보호 폴더 등) 문제 조사 후 OS 탐색기 임베드 재검토.

## 3. 이미지 모듈

- [미반영 A9] 하단 바 정보 확충 (하단 바 공간이 남는 모듈): 해상도에 더해 **용량, 종류(확장자·비트뎁스), EXIF 요약(촬영일·카메라·노출 등)**.

## 4. 영상 모듈

- [미반영 A10] **오디오 모듈 분리(ZP-audio)**: 음악 재생을 비디오 모듈에서 분리. 관련 전부 포함 —
  시작 메뉴 항목(+단축키 번호), 설정 탐색기 연결 토글, 파일 라우팅(음악 확장자 이관), 모듈 아이콘/색, 빈 상태 탐색기, 파형 시각화 이관 등.
- [미반영 A11] 재생 목록 루프 옵션: 목록 루프(기본 켬) / 현재 영상 루프(기본 끔) / 루프 횟수 1·3·무한(기본 무한). ※ 폴더 기반 연속 재생(목록 개념)부터 설계 필요.
- [미반영 A12] 재생 시작 시 파일명 + 해상도(720p 등) 오버레이 잠깐 표시 (자체 오버레이 — libvlc 기본 타이틀은 꺼둔 상태).
- [미반영 A13] 전체화면 조작 피드백 오버레이: 볼륨 변경, 시킹(±5s), 재생/일시정지 등.
- [확인] 창 크기 동일 시 시크바 길이 불변 — 가변 폭 컨트롤 고정폭화(v0.49.0~v0.53.0) 후 실기기 확인.

## 5. 녹화 · 녹음 (신규 기능군)

- [미반영 A14] **화면 녹화**: 윈도우 화면 녹화기처럼. 소리는 시스템 오디오 기본 + 마이크 입력 있으면 믹스해서 함께 녹화.
- [미반영 A15] **녹음**: 마이크 녹음.
- 소속 모듈 미정: 별도 모듈(ZP-rec?) vs 오디오/비디오 모듈 부속 — 설계 시 결정.

## 6. 문서 모듈 (ZP-doc)

- [미반영 A16] PDF 등 열린 포맷 전부 지원 — PDF·HWP·오픈오피스 등 (뷰어 생길 때 확장자 추가 — 스텁 연결 금지).

## 7. 압축 모듈 (ZP-zip)

- [확인] 우클릭 메뉴 표시명 **ZP-zip** — 코드상은 v0.33.0에서 교체 완료. 실기기에서 "WinUtil…"로 보이면:
  설정에서 우클릭 메뉴 토글 껐다 켜서 재등록 → 그래도 WinUtil로 나오면 버그로 처리.

## 8. 하드웨어(정보) 모듈

- [미반영 A17] 센서 모니터링(하단 그래프 10개) — Phase 5b (LibreHardwareMonitor: 온도·전력·팬 등, 커널 드라이버).
- [미반영 A18] 그래프 중 선택한 항목 최대 2개를 트레이 아이콘에 표시. 기본: CPU 온도 / CPU 전력. (A17 선행)
- [미반영 A19] HW 랭킹 제출 버튼 — 서버·개인정보 정책 설계 필요 (장기).
- [미반영 A20] 네트워크 상태: 연결 여부, 연결 속도, 업/다운 스트림 — Network 섹션.

## 9. 설정

- [미반영 A21] DPI: 현재 시스템 기본 배율(%) 표시 (Display 섹션).

## 10. 공통

- [미반영 A22] 하단 바 노파일 상태에서도 드라이브·파일시스템 용량/잔량 표시 (현재는 파일 연 후만).

## 부록 B. 확정된 결정 기록 (남은 작업 관련만)

1. 사진 "exit 정보" = 하단 바 여유 공간에 EXIF 정보 표시 → A9.
2. "오디오 기능 분리" = 비디오/오디오 모듈 분리, 관련 전면 반영 → A10.
3. "zp-extract" = 우클릭 메뉴 표시명에 정확한 모듈명 ZP-zip → 7장 (재등록 확인 먼저).
4. 탐색기 = 자체 구현 유지, OS 권한 조사 후 재검토 (후순위) → A4.
5. 광고 = 시작 메뉴 위치가 전부. 미션 문구 = 설정 화면·설치 스플래시 현행 유지 (관련 요구 폐기 완료).
6. 메뉴 hover 도움말 = 1초 지연 툴팁 방식 → A1.
7. 메뉴 내 H/W·Settings 위치 = 현행 확정.
8. 녹화 = 화면 녹화(시스템 소리+마이크 믹스), 녹음 = 마이크 녹음 → A14/A15.
