# ZP 요구사항 — 남은 작업 정리

> **운용 규칙**
> 1. "~~~ 구현/수정해줘" 요청은 이 문서에 항목 추가만 한다 (실개발 X).
> 2. 실제 개발은 "미반영 A?? 진행" 지시가 있을 때만 착수한다.
> 3. **A번호는 영구 ID** — 재정렬·재사용 금지. 완료되면 문서에서 항목을 제거하고 그 번호는 결번 처리. 신규 항목은 마지막 번호 다음을 부여.
>
> 상태 표기:
> - `[미반영 An]` 아직 안 함 — 지시가 오면 착수 (부록 A 번호)
> - `[확인]` 구현은 됐으나 실기기 확인/재등록 확인이 남음
> - `[보류]` 후순위 (조사·선행 작업 필요)

## 1. 셸 · 시작 메뉴

- [미반영 A24] **같은 모듈 다중 인스턴스 + 새 창 열기**: 현재는 다른 모듈 파일을 열 때만 창이 늘고,
  같은 모듈은 기존 창을 재사용해 같은 모듈 창 2개가 불가능. 추가할 것 —
  ① 명시적 "새 창" 수단(예: Ctrl+N, 메뉴 항목), ② 같은 모듈 파일을 새 창으로 여는 방법(예: Shift+더블클릭 or 옵션),
  ③ 창 재사용 규칙을 설정으로 선택(항상 재사용 / 항상 새 창). A2 번호 배지(v0.58.0 구현)와 자연 연동.
- [미반영 A31] 시작 메뉴 항목의 **선택 가능(히트) 영역 확대** — 지금보다 더 넓게 (패딩·항목 높이 증대).
- [미반영 A32] **숫자 단독 모듈 전환**: Ctrl+숫자 → **숫자만** 눌러 전환(1~5, 0=Settings, `=메뉴).
  이에 따라 정보 오버레이 키는 Shift → **Ctrl로 회귀**(v0.45.0 이전 상태).
  ※ 리스크: 텍스트 입력란·목록 타이핑 검색과 숫자키 충돌 — 포커스가 입력 컨트롤일 때는 통과시키는 예외 처리 필요.
- ※ A1(메뉴 힌트 지연 툴팁, v0.57.0)·A2(인스턴스 배지, v0.58.0)·A3(아이콘 반전, v0.59.0)·A23(확장자별 파일 아이콘, v0.60.0) 완료 — 결번.

- [미반영 A33] **좌/우 오버레이 투명도 강화 + 폭 균등화**: 이미 약간 반투명(아크릴)이나 **지금보다 더 많이 투명하게**

- [확인] Alt 우측 리스트가 줌(Zoom) 화면공유에서 안 보임 — 2연타 고정(v0.32.0)으로 우회 가능한지 확인.

## 4. 영상 모듈

- [미반영 A10] **오디오 모듈 분리(ZP-audio)**: 음악 재생을 비디오 모듈에서 분리. 관련 전부 포함 —
  시작 메뉴 항목(+단축키 번호), 설정 탐색기 연결 토글, 파일 라우팅(음악 확장자 이관), 모듈 아이콘/색, 빈 상태 탐색기, 파형 시각화 이관 등.
- [미반영 A11] 재생 목록 루프 옵션: 목록 루프(기본 켬) / 현재 영상 루프(기본 끔) / 루프 횟수 1·3·무한(기본 무한). ※ 폴더 기반 연속 재생(목록 개념)부터 설계 필요.
- [미반영 A12] 재생 시작 시 파일명 + 해상도(720p 등) 오버레이 잠깐 표시 (자체 오버레이 — libvlc 기본 타이틀은 꺼둔 상태).
- [미반영 A13] 전체화면 조작 피드백 오버레이: 볼륨 변경, 시킹(±5s), 재생/일시정지 등.
- [확인] 창 크기 동일 시 시크바 길이 불변 — 가변 폭 컨트롤 고정폭화(v0.49.0~v0.53.0) 후 실기기 확인.
- [미반영 A28] **[버그] 뮤트/소리 아이콘 반전** — 음소거 상태와 버튼 표시(🔊/🔇)가 뒤집혀 보임. 수정.
- [미반영 A30] **Fit 버튼 3옵션 상태형으로 개편**: 옵션 = A(자동) / 좌우핏 / 상하핏.
  마지막으로 고른 옵션이 버튼에 표시되고 클릭 시 그 옵션으로 동작(드롭다운으로 전환).
  선택 기억은 하지 않음 — **이번 실행 내에서도 재생 영상이 바뀌면 A로 회귀**. (1:1 버튼은 별도 유지)

## 9. 설정

- [미반영 A21] DPI: 현재 시스템 기본 배율(%) 표시 (Display 섹션).
- [미반영 A38] **연결 토글 시 기본 앱까지 스크립트로 강제 지정** (사용자 확정 — A25의 '보류' 방식 채택):
  토글을 켜면 확장자별로 UserChoice 해시를 계산해 ZP를 **기본 앱으로 직접 지정** (사용자 클릭 없이 완결).
  - 방식: UserChoice ProgId+해시 쓰기 — SetUserFTA/PS-SFTA류 역공학 알고리즘을 C#으로 자체 구현(외부 exe 동봉 지양)
  - 성공 검증: 쓰기 후 IsDefaultForExtension으로 확인 → 실패한 확장자는 A25 딥링크/대화상자로 폴백
  - 알려진 리스크(수용하고 진행): 비공식 — Windows 업데이트로 해시가 바뀌면 무력화될 수 있음.
    Win11 23H2+의 UCPD 드라이버가 일부 보호 확장자(http/https/.pdf 등)의 UserChoice 쓰기를 차단 —
    우리 대상(미디어·압축·텍스트)은 일반적으로 비보호이나 확장자별 결과 확인 필수. 백신 오탐 가능성도 유의.
- [미반영 A35] **탐색기 연결 섹션 순서 변경**: 위에서부터 **이미지 → 비디오 → 문서 → 압축**
  (확장자 연결 토글 + 우클릭 컨텍스트 메뉴 토글 모두 이 순서). ※ v0.28.0의 "압축→문서→영상→이미지" 지정을 대체.
- [미반영 A36] 연결 섹션 아래 **"Open settings.ini" 버튼**: 설정 파일을 우리 ZP-doc 에디터로 열어 직접 수정
  (A37 편집 기능 선행). ※ 확인 완료: 실제 설정 파일은 **%AppData%\ZP\settings.json** (ini 아님) —
  구현 시 결정 필요: ① 버튼이 settings.json을 열게 하고 표기만 맞추기 vs
  ② 미션 문구("all settings in settings.ini beside the app")대로 앱 옆 settings.ini로 저장 위치·포맷 자체를 이관(포터블 지향).
- [미반영 A26] **앱 업데이트 윈도우 네이티브 알림(토스트)**: 백그라운드에서 **5분 주기**로 업데이트 체크,
  새 버전 발견 시 윈도우 네이티브 알림 표시(클릭 → 설정 업데이트 섹션으로). Windows App SDK AppNotification 사용(unpackaged 지원).
  ※ 기존 확정 정책 "주기 체크 금지, 설정 진입 시에만"(v0.17.0)을 **대체**하는 지시로 접수 — 진행 시 그 전제로 구현.
  구현 시 결정할 것: 같은 버전 재알림 억제(1회만), 알림 끄기 설정 토글 여부.
- ※ A25(기본 앱 지정 보조 자동화, v0.61.0) 완료 — 결번.

## 10.1 공통

- [미반영 A22] 드라이브 정보 표시 전면 개편 (사용자 확정):
  - 표시 시점: **no file open 상태에서만** (현행 v0.47.0은 반대로 파일 연 후에만 → 뒤집기. 파일 열리면 숨김)
  - 대상: 현재 탐색기 폴더의 드라이브 하나가 아니라 **시스템의 모든 드라이브**
  - 항목·순서: **드라이브명 / 종류(SSD·SATA(HDD)·NVMe·USB 등) / 용량** — "사용량 of 전체 (사용률%)" + **채워지는 타입 사용률 그래프(막대)**
  - 내용이 하단 바 폭을 넘으면 **자동 스크롤(루프)** 로 순환 표시
  - 구현 메모: 드라이브 종류는 WMI(MSFT_PhysicalDisk MediaType/BusType)로 조회 — DriveInfo만으로는 SSD/HDD 구분 불가.
- [미반영 A27] **하단 바 버튼 통일**: ① 테두리·배경 스타일 통일(메뉴 버튼·열기 버튼 등 제각각인 외곽선 정리)
  ② 상하 정렬 전부 수직 중앙 ③ 크기는 **딱 2종** — 1칸(재생·볼륨·열기·메뉴 등) / 2칸(Fit·재생속도·리프레시 주기 등).
- [미반영 A34] **모든 버튼류에 핫키 부여**(가능한 범위): 지금 안 걸린 버튼들(Rotate 외 이미지 버튼, 배속, 자막,
  압축 Extract 등)에 단축키 지정 + 툴팁에 표기. 키 맵은 구현 시 충돌 검토해 확정.
- [미반영 A40] **창을 작게 줄여도 하단 바는 유지**: 수동 리사이즈로 창이 작아질 때 하단 바가 잘리거나 사라지지 않게.
  구현: 창 최소 크기 강제(하단 바 44px + 최소 콘텐츠 확보, OverlappedPresenter.PreferredMinimumHeight/Width 또는
  WM_GETMINMAXINFO) + 하단 바 내용이 좁아지면 우선순위 낮은 요소부터 축약/생략(정보 텍스트 → 아이콘만).
