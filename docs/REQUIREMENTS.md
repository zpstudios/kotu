- ※ A73(**리프레시 주기 목록 교체** — **50 / 200 / 500(기본) / 1000 / 2000 / 5000 ms**로

  구현 결정과 이유:
  ① **구값 이관 = "목록 밖이면 그보다 크거나 같은 가장 가까운 값으로 올린다"**(100→200, 300→500,

  이유는, 내림(예: 300→200)이면 사용자가 고른 적 없는 더 잦은 폴링이 되어 체감 부하가 갑자기 나빠지기
  때문이다. 이관은 `NormalizeRefreshMs`가 **읽을 때 1회 정규화 후 곧바로 되쓰기** 해서

  SMART 부하는 10초에 1회로 동일함을 코드로 확인(`SensorService.StorageInterval`).
