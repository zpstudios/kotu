> - `[완료]` 이미 반영됨 (참고 버전 명기)

## 부록 B. 확정된 결정 기록 (답변 요약)

1. 사진 "exit 정보" = 전체화면 안내가 아니라 **하단 바 여유 공간에 EXIF 정보 표시** → A9.
2. "오디오 기능 분리" = **비디오/오디오 모듈 분리**, 메뉴·설정 연결 등 전면 반영 → A10.
3. "zp-extract" = 우클릭 메뉴 표시명에 정확한 모듈명 **ZP-zip** 사용 → 7장 (재등록 확인 먼저).
4. 탐색기 = **자체 구현 유지**, OS 권한 문제 조사 후 재검토 (후순위) → A4.
5. 광고 = **시작 메뉴 위치가 전부**. 미션 문구 = 설정 화면·설치 스플래시 현행 유지.
6. 메뉴 hover 도움말 = **1초 지연 툴팁** 방식으로 동작·모양 변경 → A1.
7. 메뉴 내 H/W·Settings 위치 = **현행 확정**.
8. 녹화 = **화면 녹화**(시스템 소리+마이크 믹스), 녹음 = **마이크 녹음** → A14/A15.
