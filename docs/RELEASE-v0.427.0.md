# v0.427.0 — 맞춤 버튼과 메뉴 아이콘 개선

PDF·이미지·영상의 맞춤 버튼과 옵션 화살표를 하나로 이어진 간결한 형태로 통일했다. 화살표를 누르기 전에도 표시가 또렷하게 보이도록 중앙에 고정된 도형을 사용한다. 왼쪽은 현재 맞춤 방식을 다시 적용하고, 오른쪽은 네 가지 옵션을 여는 기존 동작을 유지한다.

Original·Contain·Fit width·Fit height의 아이콘을 같은 선 굵기와 여백으로 다시 그렸다. 원본 배율은 테두리 없는 `1:1`, 전체 맞춤은 화면 모서리, 가로·세로 맞춤은 방향 화살표로 구분하며 버튼과 메뉴에서 같은 도형을 사용한다. 메뉴의 아이콘 크기와 정렬도 통일했다.

맞춤 배율 계산, 작은 이미지·영상의 확대 제한, 단축키와 원본 파일은 변경하지 않는다.
