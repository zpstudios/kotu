# KOTU 현재 상태와 인수인계

## 현재 상태

- A435 v0.433.9는 필터 아이콘의 최초 기본색 캐시를 없애고 비활성 기본색 상속·활성 ThemeResource 강조색으로 테마 전환을 따른다. Core 765개·독립 검토·일반 빌드(소스531·폰트/라이선스34·진단 제외·Test 식별)를 통과했다. 별도 앱에서 수정 전 Ink Light→Dark 검정 잔류를 재현하고, 수정 후 기본색 전환·활성 Dark→Light→Dark 강조색·PNG 숨김/복귀·Dark 해제를 확인했다. Original로 디자인·모듈 전환 후 Dark 필터 적용/해제·활성 중 F11 패널 왕복과 Light 기본색도 확인했다. 정상 종료 후 최초 28키·바이트와 Windows Light를 복원했으며 검수 중 정식 창은 조작하지 않았다. [실제 검수 범위](DEVICE-CHECKS.md#native-media), 로컬 `artifacts/a435-review/product-build-verification.json`·`final-visual-review.json`·`final-restoration-verification.json`을 따른다. 제품 [`6fb335f`](https://github.com/zpstudios/kotu/commit/6fb335f5aa5536eff160b9a876865f67e8545662)을 즉시 push했고 [전체 빌드](https://github.com/zpstudios/kotu/actions/runs/45563367461)·[공식 배포 검사](https://github.com/zpstudios/kotu/actions/runs/45563367509)가 모두 통과했다(각 1,495시험·경고/오류 0). [공식 v0.433.9](https://github.com/zpstudios/kotu/releases/tag/v0.433.9)의 태그·최신·본문·8자산·피드·실제 Full/Delta 크기와 SHA-1/256·Setup SHA-256·폰트/라이선스34·진단 제외를 검증했다(`official-release/verification.json`·`workflows.json`). 교체 전 v0.433.8 설치·설정 1,182파일의 새 보호 백업과 43설정키·실행·오류 기준을 같은 검수 폴더의 `pre-update-backup/`·`backup-coverage.json`·`pre-update-request*.json`·`pre-update-startup-log.json`에 보존했다. 직전 재검증에서 자동 확인 시각만 달라 최신 설정을 별도 보존했다(`pre-update-revalidation.json`). 상시 승인에 따라 정식 Settings → Updates 다운로드·Install and restart를 직접 수행했고, 기존 H/W Info 화면으로 정상 재시작했다. Setup은 실행하지 않았다. **공식 배포와 이 PC 설치·설정 대조까지 완료**했으며 아래 지정 PC 기록과 `official-update-ui.json`·`installed-release-verification.json`·`post-update-settings-verification.json`을 따른다. [요구](REQUIREMENTS.md#a435).
