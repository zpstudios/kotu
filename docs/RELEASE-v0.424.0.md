# v0.424.0 — 탐색 선택과 도구 정렬 개선

중앙 Preview와 List의 Up one folder 항목은 파일·폴더와 같이 더블클릭으로 동작한다. Enter로도 상위 폴더를 열 수 있다. 상위 이동 아이콘은 기존 폴더와 같은 윤곽선 계열로 맞췄다.

중앙 보기·열·정렬 도구와 왼쪽 Home·Up·Filter의 높이와 세로 정렬을 통일했다. 좁은 창에서는 기존처럼 정렬 도구가 다음 줄로 이동한다.

목록이나 미리보기의 빈 영역을 클릭하면 현재 표시 순서의 첫 폴더·파일을 선택한다. Up one folder는 기본 선택에서 제외한다. 선택 없이 키보드 초점을 옮겨 와도 첫 항목부터 방향키를 사용할 수 있다. 파일·폴더를 직접 클릭하면 해당 항목을 선택하며, 별도로 체크한 항목은 유지한다.
