# v0.415.0 — 상위 폴더 아이콘 개선

중앙 탐색기의 `Up one folder` 아이콘을 사용자가 선택한 C안으로 바꿨다. 명암을 나눈 폴더와 바깥쪽 위 화살표로 상위 폴더 이동을 표현하며, 화살표도 폴더와 같은 무채색 전경을 사용한다. 테마와 비활성 상태를 따라 표시된다.

다크·라이트의 정상/hover/루트 비활성 표시와 빈 폴더에서 상위 폴더로 클릭 복귀를 실제 독립 실행 앱에서 확인했다. 정규 앱 빌드 경고0/오류0과 구조 검사20개를 통과했다. 타일 배치·클릭·키보드·체크 동작은 변경하지 않았다. 상세 검수와 시험 한계는 [A416 기록](A416-EXPLORER-SELECTION-LAYOUT.md)을 따른다.
