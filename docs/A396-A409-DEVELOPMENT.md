# A396~A409 직렬 개발 진행표

2026-10-13 착수. 시작 소스 `29b5638`, 제품 `v0.391.0`, `master` 직접 작업.
요구사항과 완료 조건의 정본은 `REQUIREMENTS.md` 상단이다.

## 운영과 검수

- 사용자가 개발을 승인했으며 착수 승인을 반복해서 묻지 않는다.
- 메인은 배치 정의·결과/diff 검수·검증·진행 기록·커밋/배포 조율만 담당한다.
  조사와 제품 구현은 아래 권장 모델의 하위 에이전트에 직렬로 위임한다.
- 이전 배치의 결과를 검수한 뒤 다음 배치를 시작한다. 하위 에이전트는 커밋·푸시하지 않는다.
- 관측, 정적 분석, 측정의 대상을 구분한다. 단위 시험이나 파서 벤치마크를 실제 UI 검증으로 세지 않는다.
- 문서만 변경한 커밋의 푸시는 보류한다. 제품 변경 배포는 기존 건별 버전·검증 절차를 따른다.
- 조사 중에는 제품 버전을 유지한다. 아래 대기 상태는 개발 승인 취소나 재확인 필요를 뜻하지 않는다.

## 결과와 근거

- A401: GPT-6 Astra/xhigh 조사·메인 검수 완료. 정본은
  `A401-DOCUMENT-PERFORMANCE-INVESTIGATION.md`. 제품 소스/버전 변경 없이 경로·합성 모델 기준선을
  확보했다. 메인은 도구를 독립 재실행했고 문서 모델 시험91/91·구조20프로젝트 검사를 확인했다.
  실제 TXT 스크롤 지연은 아직 미측정이며 다음 배치는 opt-in 계측과 장식/Wrap 비교다.
  사용자는 느린 형식을 **TXT 또는 코드 파일**로 답했다. 크기는 미제공. 이 답변을 하위 에이전트에
  전달해 긴 한 줄/많은 줄·줄바꿈·장식·편집기 대입 한도 전후를 우선 비교하도록 했다.
- A399: A401 조사 보고서 검수 및 에이전트 종료 뒤 GPT-6 Astra/high로 직렬 위임했다.
  사용자는 파일 유형·다운로드 상태를 기억하지 못한다고 답했다. 재현 조건은 미확정으로 유지한다.
  조사 정본은 `A399-ONEDRIVE-THUMBNAIL-INVESTIGATION.md`. 메인도 probe를 재실행해 속성 변경3회
  현 필터0/Attributes 필터1, 내용 변경 대조군 양쪽1, 오류0을 확인했다. Core32/32 결과를 검수했다.
- A399-b를 동일 Astra/high에 후속 위임해 v0.392.0 구현·메인 검수 완료했다. 워커 요청 직전 속성을
  다시 확인하고 열거 시점의 true는 보수 유지한다. 검수에서 활성 좌 리스트 정보도 포함하고 제한 결과의
  캐시 고착을 막았다. 전체/최종 App 빌드0경고·0오류, 8개 TRX 합계580/580 통과를 메인이 확인했다.
  정본은 `A399-REQUEST-TIME-CLOUD-GUARD.md`. 감시/재시도는 이번 변경에 포함하지 않는다.
- 실제 UI 성능 측정·배포 완료 판정은 아직 없다. 테스트 실행기 연결 제한은
  로그로 원인을 확인하고 같은 빌드의 허용된 제한 밖 실행으로 검증했다.

## 다음 인계점

사용자가 컨텍스트 누적 점검을 재확정했다. A399-b 배포 검증까지 한 묶음으로 마무리하고
다음 구현 전 인계 시점을 판단한다. 다음 권장 배치는 A401-a(TXT 장식/Wrap opt-in 계측,
Astra/xhigh), 이후 A399-a(속성 감시와 폭주/세대 보호, Astra/high)다. 구현 승인은 유지된다.

제품 커밋 `dbc3427`의 push는 자동 승인 검토에서 차단되어 원격 실행되지 않았다. 정확한 대상은
github.com/zpstudios/kotu의 master로 비밀값 없이 재확인했다. 제품 push·정식 릴리스에 대한 사용자
답변을 기다린다. 로컬 구현 승인과 결과는 유지되며 기록만의 별도 push는 하지 않는다.
