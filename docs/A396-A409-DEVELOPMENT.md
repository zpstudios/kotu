## 운영과 검수

- 사용자가 개발을 승인했으며 착수 승인을 반복해서 묻지 않는다.
- 메인은 배치 정의·결과/diff 검수·검증·진행 기록·커밋/배포 조율만 담당한다.
  조사와 제품 구현은 아래 권장 모델의 하위 에이전트에 직렬로 위임한다.
- 이전 배치의 결과를 검수한 뒤 다음 배치를 시작한다. 하위 에이전트는 커밋·푸시하지 않는다.
- 관측, 정적 분석, 측정의 대상을 구분한다. 단위 시험이나 파서 벤치마크를 실제 UI 검증으로 세지 않는다.
- 문서만 변경한 커밋의 푸시는 보류한다. 제품 변경 배포는 기존 건별 버전·검증 절차를 따른다.
- 조사 중에는 제품 버전을 유지한다. 아래 대기 상태는 개발 승인 취소나 재확인 필요를 뜻하지 않는다.
