FAQ

QUESTIONS, ANSWERED.

Is it really free?
Yes. KOTU's own code is MIT-licensed and the source is public. There is no paid tier, no account, and no telemetry.
What does it cost me in disk space?
One user-scope install, engines included. Because everything shares a single process and modules are loaded on demand, it replaces a folder full of separate utilities with one entry in your Start menu.
Do I need administrator rights?
No. The installer writes to your user profile, so no UAC prompt is needed to install or update. Only live hardware sensors (temperature, fan speed, power) need elevation — KOTU offers a one-click Restart as admin when you open that panel.
Will it take over my file associations?
Only if you ask it to. File associations and the Explorer right-click entries are off by default and live behind per-module toggles in Settings, so you can hand over just images and leave everything else alone.
Does it work offline?
Completely. Every engine — 7z.dll, libvlc, the sensor library — ships inside the download. The only thing that touches the network is the optional update check.
Is there a portable version?
Yes — KOTU-win-Portable.zip. Unzip it anywhere, including a USB stick, and run it. It updates itself the same way the installed build does.
Which Windows versions are supported?
Windows 10 version 1809 or newer, and Windows 11 — 64-bit (x64) only. No separate .NET install is required.
How finished is it?
KOTU is in active development. All six modules work and every build passes CI on Windows, but real-world polish is still landing release by release — expect frequent updates.
